# RabbitShell 外观主题规范

## Qt 0.1.37 提示与监听表头

标准 AppMessageBox 与同名冲突提示共用14逻辑px正文和按钮，正文实际排版目标行高22px，包含显式换行与无空格长路径。原生标签仍可选择复制，图标40px相对正文块居中。按钮至少84×32、间距8px，normal/hover/pressed/disabled均保留单层1px圆角描边；暗色#687086，浅色#afb8c1，默认与键盘焦点可用主题色，鼠标点击不增加外圈。样式属性首次赋值须同步repolish，不能依赖之后切主题才生效。此规则更新0.1.36及以前提示框的字号/按钮尺寸，业务和QMessageBox原生grid生命周期、roles/result/open/exec不变。

连接页签不再有右上角新建、设置、锁定按钮及corner host；使用顶部应用菜单和既有Ctrl+,设置入口，菜单焦点保留端口草稿。编辑组与终端操作按钮保留。

监听端口表头限定垂直padding为0、水平8px，最小高度取设计高度与字体高度加8px的较大值，避免通用header的8px上下padding挤压中文。排序箭头继续使用Qt原生空间，mini/full随字体与缩放更新；窄栏允许横向滚动。


## Qt 0.1.37 等待与重连状态

主交互Session本地响应慢时显示橙色“响应缓慢，等待恢复（会话保留）”，等待状态幂等，恢复后还原原连接信息。系统采集与监听复用独立Commands连接；慢采样可见标记过期并保留已有数值，不把采集失败写成主SSH断线。footer毫秒值为系统采样响应耗时（含远端执行及SSH往返），不是纯RTT；颜色仅提示、不触发断线。

同工作区重连复用原终端视图、id、分组、顺序、名称、焦点及历史。只重新打开因断线中断的shell，不重放旧命令/输入，不承诺恢复旧进程；当前仅可靠恢复原启动目录，未实现OSC7实时目录回报。启动目录失败在新shell可见提示，资源目录恢复失败明确提示并尝试连接默认目录。上传仍遵循原同目录.part和原子rename规则。

## Qt 0.1.36 页签、菜单与标准提示

主窗口系统标题栏下增加28逻辑像素应用菜单，13px文字，随全局缩放；其后仍是36px连接页签。六个入口为连接、文件、编辑、视图、终端、设置。使用Qt菜单栏原生点击/悬停切换和键盘语义，弹层复用紧凑图标菜单；系统允许菜单淡入时使用110ms opacity，不移动几何，无常驻动画计时器。菜单栏和页签带分别独占各自一条底线。

PanelTabs 总高度包含1px共享底线，原生页签和corner只占内容带，pane预留同一边线后再开始页面。编辑页签不自行绘制底边，corner无独立底边及基于未约束sizeHint的增高；活动顶部标记仍仅覆盖真实活动tabRect。顶层连接页签保留底部活动标记。

除已批准的UploadConflictDialog外，标准提示/确认使用AppMessageBox（QMessageBox子类）：原生标题栏、40px语义图标相对正文居中，正文20px边距/14px图文间距，次背景footer及单细分界，按钮至少80×28并右齐。保留Qt原有grid和业务控件，安全默认Cancel/No，只有确认按钮时设AcceptRole默认；明确指定的默认不改。Qt未翻译的标准按钮统一中文“确定/取消/保存/不保存”等，保留标准角色、结果和调用方自定义文案；文件删除使用“删除/取消”。长文本可滚动，无空格长路径必须按实际绘制布局换行，不能只测量一个可换行的副本。按钮角色、exec/open/finished、复选框及详情仍由QMessageBox管理。字体和尺寸随缩放。文件冲突对话框的外观和业务不变。

Windows QMenu在原生窗口创建前设置frameless popup+per-pixel alpha，绘制先清透明再填圆角。原生alpha不可用时按轮廓回退，不能将DWM调用成功视为合成验收。保持圆角细边、菜单输入和popup阴影；实际验证方式与边界见本版记录。

进程表为实际模型/控件：mini三列、完整六列；整体圆角8、连续表头、短列分隔、交替行色和无正文网格。CPU/RSS 按原始数值排序、右齐并按上述语义着色；PID/用户次级，运行绿色、睡眠中性。暗色选中 CPU 提亮至#D5BAFF，次级字#C0C6D9；保留刷新选择、排序、滚动及 full/compact 独立列宽记忆。mini默认列宽适配300px侧栏；前五项按真实CPU排序取值。演示截图始终注明模拟数据/未连接。

## Qt 0.1.31 按输入方式显示按钮焦点

标准 QPushButton/QToolButton 的鼠标操作只保留 hover/pressed 背景，不显示外围 accent 框或原生内层焦点框；checked 保留底色/图标色、activity 保留左侧身份条。实际焦点和原事件语义不变。Tab/Backtab/Shortcut/Space 等键盘操作显示单层焦点，主按钮用对比色描边；popup 返回保持其打开时的输入方式。

使用一个共享 Qt 事件过滤器，仅相关输入/FocusIn 事件检查按钮，模式变化时局部 repolish；不增加计时器、OS hook 或全应用逐事件 repolish，不影响 radio/checkbox、自绘 Toggle、文本框或终端。实际暗浅图及受影响回归见 [0.1.31 验证记录](RabbitShell-0.1.31验证记录.md)。下节 .30 的普通 checked 外框已由本节取消。

树内新建行保留类型图标，输入框横向占满该行剩余空间；按主题化 QLineEdit 的实际 sizeHint 加树项内边距分配行高，避免文字裁切。失败显示语义错误边框与原因 tooltip／无障碍说明，仍保留可修正文本；两主题正文、焦点和禁用态均沿用集中参数。

终端头部取消拆分方向下拉框，保留左右拆分图标，并在终止／隐藏旁增加 20px 图标、30px 点击区的最大化／还原按钮；选中态、tooltip、accessibleName 同步。最大化只影响右侧编辑／终端分区，不移除左栏或 footer。现有下拉控件只剩网卡、认证与环境，统一样式沿用 0.1.6。下文 0.1.5 的“无竖线”和 0.1.6 的四类下拉框为当时记录，以本节为当前规则。

生产控件两主题证据与范围见 [0.1.7 验证记录](RabbitShell-0.1.7验证记录.md)。

通用组件与交互基线见 [Qt 桌面应用通用开发规范](qt-desktop-guidelines.zh-CN.md)；本文记录 RabbitShell 的主题品牌、具体取值及历史验证，不作为其他项目的固定配色要求。

日期：2026-11-03。用户已经指定暗色 Dracula Theme、浅色 GitHub Light；现有统一窗口交互结构继续沿用。本文件只记录外观与交互规则，不决定正式应用的语言或框架。

## 设置行为

保留原生 OS 标题栏，服务器页签栏右端提供“设置”纯图标按钮，与“打开连接管理”加号并排；连接管理和服务器页均可使用。移除重复品牌／服务器身份与设置组成的 appHeader 整行。设置进入“外观 · 颜色主题”，展示 Dracula（暗色）与 GitHub Light（浅色）两个单选项和配色预览。按钮保留中文 tooltip、无障碍名称及 Ctrl+, 快捷键。点击立即应用并保存选择，无需重启；关闭或“完成”保留当前选择。

主题切换不重新挂载服务器内容，保留草稿、终端进程状态、目录与布局。未显示的工作区、浮动编辑器和后续打开的服务器也继承同一主题。原型首次展示默认 Dracula，有已保存主题时恢复该主题。偏好持久化仅记录主题名称等界面选择，不保存编辑内容或认证信息。

## 本轮核验

- 两套主题的编辑器背景、属性色与全局选择同步正确，连接管理、现有和新打开的服务器、浮动窗口均继承主题。
- 切换后主编辑器与浮窗的草稿保留，终端日志任务仍显示运行；切换服务器后状态保留。
- 输入与语法展示同步；查找替换仍作用于编辑内容，浮层保留在代码区域。
- 选择 GitHub Light 后重新载入原型，仍恢复 GitHub Light。
- 1024px 桌面与 360px 窄窗口下的设置可操作；窄窗口预览卡片纵向排列，没有横向溢出。
- 浏览器检查未报告应用脚本错误。

## 进程信息可读性修正

进程明细和侧栏概览显式指定表格正文、表头、内存数值和次级文字的主题颜色，避免暗色背景出现深色默认文字。选中行的数值与次级信息保持清晰。

早期 Web 原型的完整进程表使用 12px 正文与 11px 次级文字。Qt 0.1.5 统一使用 13px 正文；PID、CPU 百分比、内存数值及状态禁止拆行。固定数值列的合理初始宽度，CPU 和内存右对齐，数值列与用户列可手动调宽且刷新保留；名称列伸展、状态紧凑。编辑分组较窄时在表格内部横向滚动，保留所有列，不隐藏状态列、不挤压数字。

核验：两套主题的进程正文与选中行均清晰可读；1024px 视口下，窄分组在表格内部滚动，页面无横向溢出。合并分组后完整展示各列，内存 RSS 排序正常，浏览器未报告脚本错误。

## Qt 0.1.3 Frame 与矢量图标

Qt 0.1.5 完整进程表和侧栏 top5 共用一张大卡片：整体 8px 圆角／1px 外边框，表头仅通过整卡裁切形成上方圆角，下边直，与正文无间隙连续相接；不做独立圆角表头 pill。内部无横线、竖线或表头底线，交替底色区分行。选中行覆盖交替底色，失焦仍清楚；数值右对齐，正文 13px。表头有明确可排序箭头和左右 10px 内边距。局部 `processTable`／`processCard` 属性和轻量原生绘制只作用于进程控件，不改变其他表格；没有图形特效或动画。

## Qt 0.1.6 紧凑页签与统一下拉框

编辑组不再有额外“文件编辑”工具行，两个操作与文件页签同排、垂直居中。分屏为 20px 图标／42×30px 点击区，保留可见菜单箭头；合并为 20px／30×30px。页签溢出使用原生滚动，工具区独立保留空间。进程页删除卡片上下两行说明，保留页签、表头和数据；CPU／RSS 含义仅在列标题 tooltip 中显示，不增加可见说明区。

网卡、终端方向、认证、环境四类下拉框共用 `StyledComboBox`，正文沿用 text，框底沿用 background，列表沿用 side，选中／悬停沿用 selection，边线沿用 line／cardBorder，焦点与当前项标记沿用 accent，禁用文字沿用 muted。两套主题独立取色，不将浅色参考图直接用于暗色。

选择框 1px 细边、6px 圆角，左侧 10px 与右侧 30px 留白；右侧 chevron 独立绘制，正常／hover／focus／disabled 可区分。原生 Qt popup 容器自绘可辨 1px 圆角边框，列表四周 5px 内边距、行高至少 30px，保留已提交当前项勾选与悬停／键盘预选。默认最多八项，高度受屏幕约束后可滚动；宽度至少等于选择框，长文适度增加但不越过当前屏幕。

弹层优先在下方留 4px 间隔，底部空间不足时向上；不能按当前项位置覆盖选择框。Esc 不提交，重新打开从已提交值恢复 current／selection 后滚入可见。父窗口移动、调整大小或隐藏会关闭弹层。保留 QComboBox 的 model/view、键盘、原信号和无障碍语义，不增加搜索、多选、图形特效、动画或全局轮询。两主题实际生产控件 offscreen 图和几何验证见 [0.1.6 验证与内存记录](RabbitShell-0.1.6验证与内存记录.md)。
