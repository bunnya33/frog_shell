# FrogShell 0.1.43 验证记录

状态：集成回归和独立主线程探针通过；最终包审计及目标环境验证仍待完成。本记录不代表公开发布验收通过。

## 范围

资源管理采用共享树视觉控件，保留三列文件模型、Seti 图标、原有交互和 SafeTree 无障碍修复。目录箭头控制展开，双击目录执行路径导航。终端管理以同级行呈现组内会话，通过行位置角色绘制连接线；终端、分组和按钮操作继续使用稳定的业务 ID。

## 环境与证据

所有自动回归使用隔离配置和合成数据；SSH 会话使用不启动的队列或虚拟／回环 fixture。不得把离屏渲染和合成输入描述为真实鼠标或真实服务器验收。开发证据及检查点位于 `test-results/0.1.43/worker-integration/`；独立主验收及保全审计由主线程记录。

## 已完成的构建和回归

- Windows 11 x64、Qt 6.8.3、MSVC Release，根 `build` 编译应用及组件、工作区、文件传输和收藏测试目标成功。生产源码、头文件及静态库以 141 项 SHA-256 检查点核对，主线程独立探针使用其匹配副本。
- 集成定向回归：组件 8、工作区 20、文件传输 36、收藏及终端 5 项通过，均无失败。隔离配置、合成节点和未启动的会话队列；离屏 Qt 输入与截图不代表系统鼠标实测。
- 文件传输首次运行 34 通过、2 失败，旧测试在原生展开动画尚未结束时以最终行坐标点击。保留 `worker-integration/filetransfer-first-failed.txt`；常规点击测试改为等待布局稳定后复测，两个用例及整组通过。组件测试和主线程独立探针另覆盖动画中间帧、快速反向与模型变动。
- 主线程独立探针报告 10 通过、0 失败：包括实际行位移、展开和目录双击、局部删除、选择与新建、上传目标、3006 节点反复变化、终端组关闭及键盘焦点。深浅主题实际工作区截图经主线程视觉复核通过。
- 组件独立测试在 Qt 6.8.3 Windows 上以约 10ms 间隔采样，原生展开的最后一次可见变化约 280ms；这是采样结果，公共 API 无时长配置，主线程接受保留 Qt 默认。chevron 目标 170ms、hover 目标 120ms。

目录包、portable 单 EXE、独立包审计及 minimal PATH 启动和默认日志关闭验证以对应后续证据为准。自动化和合成数据不代表真实 SSH、真实系统鼠标、多屏或目标硬件测试。
