# FrogShell 0.1.47

## 更新包下载

- 安装包下载连续无数据的容忍时间由 15 秒改为 120 秒。版本信息查询仍使用 15 秒无数据、30 秒总时限。
- 下载遇到连接中断、停顿超时或 HTTP 408/500/502/503/504 时，最多自动重试 3 次，默认间隔 1、2、4 秒；等待期间可取消。服务返回 Retry-After 时遵守等待要求，过长的等待交给用户稍后重试。
- 自动重试保留本地片段，以 HTTP Range 请求继续下载；每次从固定仓库的发布地址重新获取跳转，避免重复使用过期的 CDN 地址。服务器不支持续传时安全地重新下载。
- 重试耗尽后，有效片段在本次程序运行内保留，可点击“重试下载”继续。主动取消、重新检查版本、切换更新源和退出程序都会清理片段；不支持退出程序后继续上次下载。
- 下载总时限仍为 20 分钟，包含重试等待，不会因重试而无限延长。总时限到达后清理本次片段。
- 界面区分无数据超时、总时限、网络错误和软件锁定取消，并显示重试次数。锁定软件仍会取消更新，不在锁定状态安装。
- 继续验证下载来源、续传范围、完整长度和 SHA-256；TLS、范围、摘要或本地写入错误不会盲目重试，也不会准备安装。

## 编辑器

包含此前已确认的官方 Scintilla 编辑器迁移，改善快速反复拖选和长混排行的选择性能。保留语法高亮、错误红线、查找替换、高级搜索定位、字体/行距、分屏、浮窗及未保存保护。详细范围、性能实测和跨平台验证限制见 `editor-scintilla-migration.zh-CN.md`。

## 下载

Windows x64 同时提供 `FrogShell-0.1.47-portable.exe` 和 `FrogShell-0.1.47-setup.exe`，固定从 https://github.com/bunnya33/frog_shell/releases 更新。

旧版下载器需要先完成这一次更新才会获得新规则；若旧版仍下载失败，可直接从发布页下载安装。
