# RabbitShell 0.1.27 资源操作设计

本文描述 0.1.27 资源操作的实现范围和验证边界。

资源树在已确定的非根目录顶层显示独立的 `..` 导航行，双击使用现有父目录导航；该行不参与文件操作。排序始终依次保持导航、草稿、目录、文件；大小排序中的目录按名称排列，文件按实际大小排列，不扫描远端目录大小。

剪切仅支持同一已认证服务器内的 SFTP 移动，使用 rename；复制到本地先通过传输队列准备本机暂存，完整成功后才发布本地 URL。本地文件或目录粘贴上传为副本，保留本地源。内部拖拽与剪切使用相同移动机制，目录整行显示目标，释放后默认询问；普通文件仍支持原 Windows 原生拖出复制。测试使用私有数据和 offscreen，不代表真实 Explorer 验收。

远端复制的各个根项目分别暂存，避免不同目录的同名项目合并。为保证可在不同平台使用，导出时会保守地将仅大小写不同的同级名称视为冲突；遇到本地不可表示的名称、名称冲突、跳过项或下载失败时，整批不发布到系统剪贴板。

资源树 Ctrl+Z 和空白处菜单可撤销本次会话内最近的完整文件操作批次：新建的普通文件可在大小和修改时间仍匹配时删除，新建目录只有仍为空时才能删除；重命名与移动按原路径不存在、父目录有效、类型匹配等条件逆向 rename。新建上传目录仅记录根目录，非空时不能撤销；合并已有目录的上传只记录新建项。已修改的新文件不会自动删除，请检查后自行删除。删除或覆盖不可撤销，包含它们的批次阻断撤销，不会跳过而撤销更早操作。编辑保存、权限修改、下载和终端命令不进入该历史；没有重做。

历史只保存在本机内存，按配置身份和实际认证的主机指纹分开，最多保留 100 个批次、4096 个效果和 4 MiB 元数据。同身份的相关连接全部结束后清除，程序重启不保留；不保存远端文件内容，也不创建远端恢复目录或备份。若连接中断造成结果未知，撤销会停止；关闭相关连接并重新连接会清除这段会话历史。同服务器变更使用本机跨进程互斥，繁忙时包括无关路径的保存和上传也会提示稍后重试，草稿保留；读取、列表和终端不使用此锁。

编辑期间修改保留在编辑窗口中；关闭未保存文件时提供保存、不保存和取消。用户主动保存或上传时，现有机制先在目标目录写入短期 `.part` 文件，再完成替换或提交，正常成功与取消时清理。进程异常退出或断线可能留下临时文件；应用不会自动扫描或删除远端残留，需要用户检查并主动清理。服务管理中创建配置或启用服务仅在用户明确执行相应操作时进行。

验证使用私有 loopback SFTP、私有数据和 Qt offscreen，覆盖正向操作、撤销、覆盖及删除阻断、变化和非空目录保护、批次、拖放、快捷键以及临时文件清理；测试结果和限制见《0.1.27 验证记录》。
