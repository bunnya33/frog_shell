# FrogShell 0.1.55

- 编辑器查找框支持用八点手柄横向移动，从左侧调宽，并在本地保存宽度和位置。调宽条在常态可见，悬停和拖动时有对应反馈。空查询显示「无结果」。关闭查找框会清除搜索高亮，保留当前匹配项的普通选区和滚动位置。
- 底部采用紧凑的「终端 / 端口 / 服务」页签。终端列表悬停时提供拆分和关闭操作，调整终端面板大小时短暂显示列数和行数，端口空列表提供「转发端口」入口。

Windows 本地对查找交互、圆角绘制、外观、文档搜索、终端和工作区运行了回归测试。端口管理通过了 20 项本机 SSH 集成测试。GitHub Windows Release 流程为正式版本构建并检查安装版、单文件便携版和 SHA-256 校验清单。
