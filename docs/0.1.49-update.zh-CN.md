# FrogShell 0.1.49

## 编辑器查找

- 修复查找栏开启时，每次修改文档都会重新选中搜索结果，导致继续输入误改匹配文本的问题。
- 输入、删除、粘贴、撤销和重做只刷新匹配计数与高亮，保留正在编辑的光标、选区和滚动位置。
- 查找等待期间，用户已移动光标或建立选区时，不再由迟到的搜索结果抢走位置。主动查找、上一个/下一个及替换后定位继续生效。

## 更新下载

- 每次下载入口请求携带独立的刷新标记并禁用缓存，减少重复使用缓存跳转的情况。
- 网络停顿、连接中断或临时服务错误后，保留本地片段并切换到新的 HTTP/1.1 连接。发布信息包含附件 ID 时，在同一仓库的 Release 下载入口和公开附件 API 入口之间交替尝试，无需 GitHub 登录或令牌。
- GitHub 附件 CDN 返回过期跳转相关错误时，重新请求下载入口，不直接重复过期地址。
- 收齐预期字节并通过 SHA-256 校验后直接完成，避免因为迟迟没有收到连接结束通知而停在最后阶段。
- 保留既有的范围、长度、摘要、HTTPS 和来源校验。下载仍为 120 秒无数据超时、20 分钟总时限、最多 3 次自动重试；主动取消、软件锁定或退出仍会清理片段。
- 启用日志时记录更新请求、响应、重试、完成与失败的结构化事件及字节进度，不记录带签名参数的下载地址。日志默认关闭。

## 手动更新

关于/版本更新和设置的更新页面常驻显示可点击的手动下载地址：

https://github.com/bunnya33/frog_shell/releases

无需先成功检查更新；自动下载失败时也可直接打开，选择便携版或安装版。

Windows x64 同时提供 `FrogShell-0.1.49-portable.exe` 和 `FrogShell-0.1.49-setup.exe`。旧版下载器需先完成这次升级才会获得新规则；旧版下载失败时，请使用上述发布页手动下载安装。
