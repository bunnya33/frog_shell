# RabbitShell 0.1.34 验证记录

日期：2026-11-11。Windows x64 / Qt 6.8.3 / MSVC Release。此次落实已批准的新版 Qt 工作区、连接管理和系统状态布局；六张独立原型保留为设计参考，正式证据使用生产控件与离线测试数据重新生成。

## 实现范围

- 顶部连接页签36、活动栏44、资源侧栏默认300、同级工具带36、dock默认280、终端管理默认170、footer24，使用现有应用缩放绑定。1440×900为客户区基准，首次和重置窗口受屏幕范围约束，正常恢复窗口记忆不变。
- 资源树、收藏与终端管理树采用限定侧栏背景；路径、过滤、树行和收藏保持紧凑对齐。普通文件/收藏的选择、排序、拖动、快捷键和既有菜单保留。收藏默认两列填满，长路径省略并保留提示。
- 编辑组页签与操作同行；活动标记只覆盖实际页签，顶部连接与dock使用底部活动线。保存使用Save矢量图标；长路径按可用宽度省略。分屏和浮窗继续迁移同一编辑器，隐藏文件图标明确归属Editor父对象。
- 主分区由单一共享边/分隔手柄绘制，1px视觉线和Qt扩展拖动命中区分开。卡片上层轮廓保持四角连续，状态与进程卡片圆角8；没有增加常驻计时器、阴影或位图缓存。
- 系统身份分主名称与次级系统/架构行，资源、网络及进程按数值类型着色。CPU和网络首轮未就绪为“—”，缺CPU/内存不阻断进程与延迟更新。新增系统名称/架构仅通过现有SSH只读读取可用系统信息，不能读取时降级，不安装远端工具。
- mini真实进程表按CPU取前五项；完整表保留六列、PID增量刷新、选择/滚动/排序和独立列宽记忆。数字右齐、CPU/RSS分色，运行绿、睡眠中性；暗色选中CPU与次级文字分别提亮至#D5BAFF/#C0C6D9。
- 连接管理保留真实五列、分组、收藏子项及原操作。普通连接46px，收藏子项28px；详情按实际状态显示“连接”或“打开工作区”。

具体颜色与度量见[外观主题规范](RabbitShell-外观主题规范.md)；共享边、字体基线、缩放接缝和语义颜色规则同步补入[Qt通用规范](qt-desktop-guidelines.zh-CN.md)。0.1.31按钮焦点规则与0.1.33冲突消息框继续保留。

## 最终验证

12个受影响套件最终均为0失败，QtTest合计288项通过、21项跳过（统计含各套件初始化/清理）。套件为appearance、rounded_surfaces、processes、editor_groups、workspace、controls、menus、ports、services、terminal、file_transfers、bookmarks。跳过项需要另行启动的隔离SSH/SFTP/systemd/隧道fixture，本轮未运行这些网络集成，不将跳过项计为通过。

首轮发现的旧尺寸断言已按新规格更新；mini滚动保持测试使用明确限高的私有表格。菜单复验日志确认额外任务仅为延后终端布局的两个resize维护任务，最终仍断言没有文件任务/命令，仅容许属于现存终端且行列数有效的resize。终端测试包含光标、清屏、历史与alternate-screen回归。

几何与绘制检查覆盖暗浅主题、100/120/144%应用倍率，以及QT_SCALE_FACTOR模拟的DPR 1/1.25/1.5/2，共24组主题/倍率/DPR组合。验证实际可拖动的扩展手柄、连续边线像素、页签实际矩形和18px图标、工具带/footer高度、最大化/还原后文档对象及文本保持、800×480高倍率状态侧栏滚动和完整进程表横向滚动。终端管理总宽随缩放为170/204/245，操作列实际为60px基线，名称剩余空间足够显示shell；保留用户拖宽的基础宽度。

测试修复了终端表头默认stretchLastSection覆盖固定操作列的问题。样式占位符连续编号；活动页签超长顶线来自旧TabBar额外绘制，已移除。几何fixture注册配置身份，消除“连接已删除”造成的无关状态栏。初次截图测试的浅色行曾因测试草稿恢复弹窗停住，已结束该私有离屏进程并在每行结束清理测试草稿，未操作用户实际应用。

最终六张1440×900生产截图为workspace-dark/light、manager-dark/light、system-info-dark/light，存于包外`test-results/0.1.34/`。截图是客户区，不含OS标题栏。菜单suite的小图会使用同名manager文件，最终在全部suite之后仅重跑生产证据函数，确保全幅图没有被覆盖。所有系统值来自明确的两次合成监测及有界历史fixture，demo footer始终注明“模拟数据·未连接服务器”。未向正式运行路径注入固定采样值。

## 有限生命周期与内存

独立offscreen进程，3轮预热后25轮编辑器打开/关闭，包含128KiB/1MiB文件、少量4.75MiB文件、移组、浮窗收回、查找、编辑撤销和Discard。新增跟踪隐藏文件图标，关闭后其与Editor、文档、高亮器、页签按钮等被跟踪对象均释放，trackedAlive恒0；Editor/高亮器关闭后均0。工作区有1个网络图例富文本持久文档，关闭后documents恒1；句柄恒257。

关闭后的全局widgets在round0–11为379，round12首次Discard模态之后为380并保持至结束。这个未单独跟踪的widget一次性出现，不能据此宣传全局零泄漏；既有同类诊断边界见[0.1.6内存记录](RabbitShell-0.1.6验证与内存记录.md)。本轮不为这一稳定小量未知对象扩大生产修改。

25轮关闭样本Private Bytes约34.4–36.8MiB（首36,040,704，末37,863,424字节）；Working Set首58,634,240、末60,280,832字节。未强制裁剪堆或工作集。这是有限单进程场景，不能外推所有库无泄漏或完整实际工作负载的最低内存。

## 交付证据与范围

打包流程在全部源码、测试、文档与版本定稿后冻结source-after JSON/ZIP，再生成0.1.34独立目录及portable单EXE，逐文件核对approved/generated/目录/PE内嵌的size与SHA，检查包内文档与冻结源、应用与Release一致。目录/portable分别使用独立data-dir离屏启动检查，最终结果在包外`test-results/0.1.34/`的审计与smoke报告记录；启动烟测结束方式由私有测试进程明确标注，不当成优雅关闭或崩溃复现。

开工保全范围为实际存在的0.1.29–0.1.33共10个旧目标、475文件；不恢复缺失的0.1.12–0.1.28，不声称其存在。批准的8项设计参考（含六图）保持不变。

本轮没有访问真实服务器、凭据或可见桌面；离屏剪贴板测试使用Qt私有平台。DPR检查属于仿真，未实测混合多屏、DWM桌面合成、Linux/macOS或真实SSH连接下的全部业务；保留这些限制。
