# FrogShell 0.1.40 实施说明

## 终端历史与主屏重排

问题由真实 Terminal 控件的离线输入复现：两张硬换行表格跨越历史区与可见主屏，180→72→180 列后由 15 行增至 37 行。旧代码只拆分历史物理行，无法恢复软折行边界。新版在 libvterm 状态层移动行信息前捕获权威 continuation 标记，历史每行连同单元格、行信息及受保护单元格位图一起保存。

重排把历史区和主屏视为同一逻辑流，因此能合并跨越接缝的软折行，同时保留程序主动换行、连续空行和真实尾空格。宽字按完整字形搬移，组合字和 ANSI 属性随单元格保留；DECSCA 的隐藏 protected_cell 位通过私有桥接显式传递。缩小后的主屏尾部在同一次 vterm_set_size 事务中导入，映射光标、pending wrap、组合字锚点及备用屏期间保存的主屏光标。备用屏继续使用 libvterm 原来的固定网格路径。

历史仍限制为 2000 行及 2MiB，计入逐行元数据和位图。旧历史边消费边释放，新历史即时限额，仅额外保存有界的新主屏尾部和一行工作缓冲，不保存无限日志缓存。选择与非底部滚动锚点按字形序号映射。清屏保留既有安全边界，光标逻辑行跨历史时仍拒绝清屏，不截断提示符或输入草稿。

现有 Terminal::sizeChanged→工作区 resize job→libssh2 PTY 调整路径保持不变；本轮不改 session。测试检查稳定后的发出尺寸与本地网格一致，调整尺寸不额外发送 PTY 输入。不清屏、不重启会话、不重发命令，也不在服务器安装工具。客户端只重排已收到的单元格，不能重新计算 PM2 已输出表格的业务列宽。

libvterm 仍为固定归档及源文件 SHA-256，CMake 对每个替换锚点做唯一性检查，只生成 build 下的私有补丁文件；上游目录与公共 vterm.h 不变。扩展与回调均按终端实例保存。细节见 [libvterm 补丁记录](../third_party/patches/libvterm-0.3.3.md)。

## 编辑器三态高亮

聚焦且没有文字选区时，当前行显示一条物理像素的完整矩形边框；文字选区优先并移除该行框。Ctrl+F 定位期间当前命中行使用淡底色，匹配使用棕黄色块，当前匹配另加强调。焦点移入搜索框仍保留定位提示；关闭、清空、无结果、无效表达式或手工移动/选择后恢复对应状态。沿用两套主题，无新设置，不更改字体、行距、文档内容、dirty 状态或撤销栈。

集成回归另外发现查找框 Return 事件在导航后冒泡到编辑器，导致命中词被换行替换。现由查找框事件过滤器接收 Return/Shift+Return（含数字键盘 Enter），完成一次导航后终止冒泡；测试保留真实按键、选区内容及正文未变的断言。

## 验证边界

使用隔离配置、离屏控件及本地合成 VT 输入。红绿证据、暗浅截图、专项与独立 probe 的最终结果位于 test-results/0.1.40；所有 main-* 文件由主线程维护。用户原 PM2 会话尚无完整 VT 录制，不能据此宣称已复现其真实服务器现场。原生桌面合成、真实 PTY 网络时序及 macOS/Linux 待对应环境验证。0.1.39 冻结源码/交付包及已有 dist 保持不变；独立验收通过后才冻结和打包 0.1.40。
