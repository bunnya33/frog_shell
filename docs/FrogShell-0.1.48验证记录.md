# FrogShell 0.1.48 验证记录

## 范围

连接管理环境徽章和连接状态图标。使用 Qt 列表代理按当前主题绘制，无每行 QWidget、无额外网络请求、无动画计时器。收藏目录子项沿用原有绘制方式，文本和辅助功能内容保留。

## 验收

在临时配置和离屏平台中检查 Dracula / GitHub Light、默认与放大界面、生产/测试/个人/自定义环境、选中行，以及已连接→连接中→未连接的状态转换。确认状态变化复用原有条目并保持其他行选择，打开但未连接的工作区不显示为已连接。

检查徽章底色和边缘、图标与文本的垂直对齐、选中行可读性，以及缩小列宽时的裁剪。截图和测试日志保存在 `test-results/0.1.48/`。

本地最终外观测试 53 项、菜单测试 34 项、收藏目录测试 12 项通过。收藏目录的 1 项私有环回 SSH/SFTP 集成测试因未启用专用夹具而跳过；未连接实际服务器。深浅主题的默认、放大、连接中与窄列截图已复核。

Windows Release 工作流从同一标签提交构建便携版和安装版，执行隔离启动与安装/卸载检查。发布后复核公开附件、SHA256SUMS、GitHub 摘要、源提交和云端验收报告，记录到 `test-results/0.1.48/main-release-report.json`。

## 边界

本次使用合成服务器和连接状态，不连接或修改实际远端服务器。图标反映主 SSH 连接，单独运行的隧道或服务连接不等同于主连接已连接。Windows 离屏验证不替代 Linux/macOS 的实际窗口系统验收。
