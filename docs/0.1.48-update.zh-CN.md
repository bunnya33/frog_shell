# FrogShell 0.1.48

- 连接管理的环境列改为带圆角底色的文字徽章：生产红色、测试橙色、个人紫色，其他导入环境使用蓝色。
- 状态列增加图标和语义颜色：绿色勾选表示已连接，橙色时钟表示连接中，灰色断开标记表示未连接。保留文字和悬停提示。
- 连接中、认证等待、连接成功和断开时跟随实际 SSH 主连接状态更新；打开工作区不会被当成已连接。
- 同时适配 Dracula / GitHub Light、列表选中状态和界面缩放。徽章与图标直接由列表代理绘制，不为每行创建额外控件或动画计时器。

Windows x64 同时提供便携版与安装版，更新源保持为 https://github.com/bunnya33/frog_shell/releases 。
