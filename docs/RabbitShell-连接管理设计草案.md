# RabbitShell 连接管理设计草案

更新日期：2026-11-03。状态：用户已选择连接管理与服务器工作区合并到一个主窗口；本轮制作统一版交互原型供评审，细节不代表全部已确认。本阶段仅确定产品与交互，不选择语言、框架或 SSH 实现方式。

## 1. 与现有工作区的关系

连接管理与服务器工作区共用一个主窗口。全局层级为“连接管理＋各服务器工作区”；各工作区内部继续使用已确定的完整服务器状态、资源管理、文件页签和终端分组。

- 顶部全局页签示例：`连接管理 | [测试] staging-api | [生产] prod-web-01`。它与文件编辑器内的页签是两个层级；连接管理页签固定，不提供关闭按钮。
- 首次启动、没有打开任何工作区时，显示连接管理页。
- 打开连接管理页、切换服务器工作区，不终止现有终端，也不丢失未保存文件或中断传输。
- 同一连接配置默认只打开一个工作区。重复连接直接切回，断开后在原页签重连；不以当前目录作为去重条件。首版移除“新建独立工作区”“在新窗口打开”入口。不同账号／不同配置可并存，创建配置时提示可能重复。
- 连接配置保存地址、认证方式等信息；工作区保存本次打开的目录和布局。资源管理器切换到 `/home` 不应自动改写连接配置的默认目录。
- 编辑连接配置只影响后续连接；正在运行的会话保留其实际连接信息，避免界面显示新地址、实际仍连着旧地址。

## 2. 页面布局

| 区域 | 建议内容 | 规则 |
| --- | --- | --- |
| 左侧 | 全部连接、最近使用、收藏、自定义分组树 | 前三项是视图，不产生重复配置。分组可折叠、重命名、拖动排序。 |
| 顶部 | 搜索、新建连接、新建分组、导入及更多操作 | 搜索连接名称、地址、用户名及分组。导出等低频操作收入更多菜单。 |
| 中间 | 紧凑连接列表 | 主列为名称、地址、用户、状态；非默认端口随地址显示，最近使用时间可作为次要信息。不在此重复显示 CPU、进程等工作区监控。 |
| 右侧 | 可收起的连接详情 | 单击选择后查看完整地址、认证方式、默认目录、备注及已打开工作区；空间不足时改为抽屉。密码和私钥内容不展示。 |

使用整行点击、整行右键，列表支持 Ctrl／Shift 多选；不增加每行复选框或独立的“已选项目／下载所选”操作栏。批量操作通过右键完成。

## 3. 连接列表交互

| 操作 | 建议行为 |
| --- | --- |
| 单击 | 选择连接，显示详情；不立即发起连接。 |
| 双击或 Enter | 连接并打开工作区；已打开对应工作区则直接切换。连接进行中再次操作不重复创建。 |
| F2 | 修改连接显示名称，不更改服务器地址或远端主机名。 |
| 右键 | 连接／切换工作区、编辑连接、重命名、复制配置、移动分组、收藏、复制地址、导出、删除配置。根据状态提供取消连接、重试或断开会话。顶层服务器页签右键提供切换、断开／重连和关闭此工作区。 |
| 拖拽 | 调整顺序或移入分组；不隐式发起连接。 |
| 多选 | 批量移动分组、导出或删除本地配置；首版不提供批量执行远程命令。 |

建议首版分组只承担整理用途，不叠加复杂的账号、认证及跳板配置继承。

## 4. 新建和编辑连接

基本信息直接显示，高级项折叠；认证输入根据所选方式切换，避免同时堆满全部字段。

| 类型 | 字段与默认规则 |
| --- | --- |
| 基本信息 | 显示名称、主机地址、端口（默认 22）、用户名、所属分组。用户名不默认设为 root。 |
| 密码认证 | 密码、是否记住密码；默认不记住，连接时可临时输入。保存配置允许不保存密码。 |
| 密钥认证 | 选择本地私钥文件；加密私钥需要解密口令，支持连接时输入。路径与文件内容分开处理。 |
| SSH Agent | 使用已有代理中的身份；实际不可用时明确提示，不静默切换认证方式。 |
| 工作区入口 | 初始目录默认当前账号主目录；可填写指定目录或选择优先恢复最近目录。策略必须明确展示。 |
| 可选信息 | 备注、生产／测试环境标签。标签在工作区中继续显示，避免认错服务器。 |
| 高级连接 | 跳板机、连接超时、保活设置。普通用户无需展开即可连接。 |

底部提供“取消”“保存”“保存并连接”，另有“测试连接”入口。

- 保存只保存配置；保存并连接完成校验后进入连接流程。
- 测试连接检查 SSH 握手与认证，不以 Ping 成功作为 SSH 可用的依据；测试成功后释放测试会话，不创建工作区。
- 主机地址、端口和用户名给出就地校验。相同地址、端口与用户名已有配置时提示可能重复，允许不同认证或用途的配置并存。
- 记住的密码或密钥口令使用本地安全存储，不写入普通连接配置或明文导出文件。
- 复制配置默认不复制保存的密码、私钥内容或口令。

## 5. 连接流程与状态

常规流程：选择连接 → 建立 SSH 连接 → 必要时确认主机指纹、输入凭据 → 打开目录和工作区。

| 状态／情况 | 界面反馈与下一步 |
| --- | --- |
| 未连接 | 表示应用尚未建立会话，不写成“服务器离线”，也不把所有保存的服务器持续当作监控目标。 |
| 连接中 | 显示当前阶段，例如连接主机、连接跳板机、等待认证、打开目录；可以取消。 |
| 等待输入 | 指纹、密码、私钥口令或动态验证码提示有明确主机身份；不显示无限加载。 |
| 已连接 | 标记已打开的工作区数量，提供切换入口；详细延迟继续放在对应工作区左下角。 |
| 连接失败 | 区分无法解析地址、超时、连接拒绝、认证失败、密钥不可用和跳板失败；提供重试、编辑配置、查看脱敏详情。 |
| 指定目录不可用 | 已连接状态保留，提示目录不存在或无权限，可选择主目录或修改目录。 |
| 已断开 | 保留工作区中的输出、草稿和任务信息，提供重新连接；不承诺恢复普通 SSH 会话中的原有进程。 |

首次连接展示服务器指纹，允许确认信任或取消。已记录的指纹发生变化时暂停连接，明确展示变化及核验入口，不自动接受新指纹。

认证失败不循环重试同一份错误凭据。网络恢复后的自动重连策略单独设计，并允许取消；不能因连续点击创建多个重复连接。

## 6. 断开、关闭与删除

- 连接管理为固定页签；切走即隐藏页面，点击该页签或顶部“＋”随时呼出，不断开任何工作区。
- 断开某个工作区时，列出其终端、未保存文件和未完成传输的影响；草稿保留，传输转为等待或暂停。
- 一个连接配置对应一个工作区。断开连接仍保留页签；关闭工作区会结束其终端、取消未完成任务并关闭所属浮窗，其他服务器不受影响。
- 删除连接配置需要确认，含义为移除本地配置；它与终止当前会话是不同动作，不删除远端文件。删除时仍有活动工作区的提示和保留方式需在原型中展开。
- 删除分组默认把连接移到“未分组”；如果提供连同配置删除，必须明确选择并显示数量。
- 退出应用时统一汇总所有工作区的未保存文件、终端、前台任务、传输和浮窗，提供取消／保存全部并退出／不保存并退出。保存失败或冲突时停留在问题所属工作区，不继续关闭。
- 主窗口关闭默认进入退出流程，不冒充最小化。系统最小化保留连接；托盘常驻另行设计。原型中的退出仅改变演示状态，不关闭浏览器或真实应用。
- 浮动编辑器标题显示环境＋服务器名，路径栏显示完整路径，提供返回所属工作区并收回文件。浮窗随所属服务器页签隐藏和恢复；独立系统窗口与跨屏能力后续实现。

## 7. 导入与导出

- 支持导入现有 SSH 配置，尤其是已有 VS Code Remote SSH 用户使用的 `.ssh/config`。
- 导入先预览名称、地址、用户、端口、密钥路径及跳板关系；标出无法识别的配置，禁止静默忽略后声称完全兼容。
- 对包含脚本执行的复杂连接项，先展示原始配置和支持边界；导入动作本身不执行命令。
- 导入为应用内连接配置，保留来源信息；编辑时不自动覆盖原始 SSH 配置文件。
- 重复项目提供跳过、另存或更新选择；更新现有配置需要展示差异。
- 导出默认只包含连接配置，不包含密码、私钥内容或口令。受保护的凭据备份单独讨论。

## 8. 建议的设计推进顺序

1. 主页面：空状态、分组、搜索、连接列表、详情和右键菜单。
2. 新建／编辑：密码与密钥两种常见认证，基本字段和高级项折叠。
3. 连接流程：连接中、取消、凭据输入、首次指纹、失败重试、成功进入工作区。
4. 生命周期：切回已有工作区、多服务器切换、断开、关闭、退出与配置删除。
5. 导入导出和跳板机配置。

云同步、团队共享、凭据保险库、复杂分组继承和批量远程操作建议后置。是否加入首版，以后续讨论为准。

## 9. 待继续确定的设计点

- 统一窗口主页面与全局工作区页签的具体样式；单窗口方向已确认。
- 首版是否需要多个层级的分组，以及列表中环境标签的展示方式。
- 默认打开主目录、指定目录或最近目录的选择方式。
- 活动工作区关联的连接配置被删除后的展示与恢复方式。
- 导入配置、SSH Agent、跳板机等能力的首版范围。

这些问题不阻碍先制作主页面与新建连接的原型；原型中应标明采用的默认规则，避免把草案当成已经确认的需求。

## 10. 早期连接原型覆盖与边界（历史记录）

以下记录对应独立连接管理原型；其中“简化工作区”“新窗口预览”和按目录区分工作区已被第 11 节的统一版方案替代。

- 已提供：全局连接管理页和工作区页签、单层分组、全部／最近／收藏视图、搜索、可收起详情、整行选择与双击连接、Ctrl／Shift 多选、F2 重命名、右键操作、连接拖动排序和拖入分组。
- 配置操作：新建／编辑／复制、分组新建与重命名、批量移动、删除确认、分组删除后移入未分组。复制与导出不包含密码、私钥内容或口令。
- 新建表单：密码／私钥／SSH Agent、所属分组、初始目录策略、环境标签、跳板机、超时、保活与备注；基本校验、重复配置提示、保存与保存并连接分开。
- 连接流程：分阶段反馈、取消、首次指纹确认、示例密码输入、成功进入工作区、失败重试及编辑配置；测试连接不创建工作区。
- 可通过设计控件预览：网络超时、认证失败、私钥不可用、主机指纹变化、目录不可用等状态。默认 sandbox-01 用于首次连接和密码输入，archive-node 用于网络失败，prod-db 用于认证失败。
- 导入支持粘贴和填入示例 SSH 配置，先预览，再导入；支持保留两份或跳过已有连接。无法识别的块明确列出并跳过，不执行其中命令。直接读取本机 SSH 配置文件与更新既有配置的差异确认尚未制作。
- 工作区仅作连接后的衔接预览：可切换、编辑示例内容、保存、断开及关闭；切换保留草稿，同目录已连接工作区不重复创建。完整工作区继续以此前工作区原型为准。
- “新窗口”目前展示为新窗口的工作区预览；不代表已经实现系统原生窗口。多层分组、完整 SSH Agent 密钥选择、跳板链、加密私钥口令与动态验证码尚待后续细化。
- 所有 SSH、身份验证、文件保存与会话状态均为模拟，不发起真实网络连接，不读取真实私钥。凭据输入不写入原型持久状态；“记住密码”仅演示选项含义。

已核验的主要流程：搜索、空表单校验、保存连接、F2 重命名、双击连接、首次指纹及示例密码、成功进入工作区、切换后保留草稿、不重复创建工作区、失败重试和取消、导入预览与跳过不支持配置、导入后批量移动分组、测试连接不创建工作区、断开影响提示，以及 1024px／360px 宽度下的布局。原型浏览器检查未报告应用脚本错误。

## 11. 统一窗口原型（2026-11-03）

- 入口：`rabbitshell-unified-prototype.html`。复用已评审的完整工作区与连接管理功能，保留旧原型作为历史版本；不再展示简化的“工作区衔接预览”。
- 默认打开测试服务器，并预置生产服务器页签，方便对比归属和切换。新连接进入完整工作区，默认一个终端；初始两个演示服务器预置分组终端，便于查看分组效果。
- 每个服务器拥有独立目录、文件草稿、编辑分组、终端记录、浮窗与传输。切换只改变可见页面，不重建内容；后台模拟传输继续。
- 服务器页签显示环境、状态点和未保存标记；应用标题显示实际服务器、账号和地址。页签上的状态点与所属工作区连接状态同步，详细延迟仍在左下角。
- 重复连接同一配置定位到已有工作区；工作区内更换目录不产生重复页签。重连复用原工作区，保留目录与草稿，输出注明原进程未恢复。
- 关闭工作区和退出应用的确认清单来自当前真实交互状态，覆盖浮窗文件的未保存修改，不使用固定演示计数。保存动作复用原有权限、连接失败和远端冲突保护。
- 文件浮窗新增环境与服务器身份、返回工作区并收回操作；右下角传输面板标题显示所属服务器，继续保留此前精简过的内容。
- 系统最小化、托盘、真正独立系统窗口及跨屏拖动尚未实现；当前浮窗用于评审设计。所有连接、文件保存、权限与传输均为模拟。

本轮已核验：两个服务器的草稿和浮窗相互独立；重复连接复用页签；新连接进入完整工作区并显示正确账号与目录；目录切换后往返服务器仍保留；单终端管理栏隐藏、新建后出现、关闭剩一项后隐藏；拖出文件页签形成带服务器归属的浮窗并可收回；Ctrl+F 仍为代码区域内的浮层；断线传输进入等待、重连复用页签且保留草稿与历史输出；保存失败阻止关闭；关闭一个服务器不影响另一个；退出时按服务器汇总影响；1024px 和 360px 布局，窄屏详情抽屉不覆盖全局页签。浏览器检查未发现应用脚本错误。
