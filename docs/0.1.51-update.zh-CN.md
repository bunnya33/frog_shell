# FrogShell 0.1.51

## 搜索高亮

- 修复查找栏开启时，修改无关文本也会先清空所有高亮、等待重新查找后才恢复的闪烁。
- 未受影响的匹配项保持可见；在它们前面插入、删除、粘贴或撤销文字时，高亮随文本位置移动。
- 编辑某个匹配项时仅移除被修改的那一项，其余高亮保留。全字匹配和正则上下文由后台重新核对，结果完成后统一更新。
- 保留当前匹配项的橙色标记；即使前面新增了匹配项，也不会误把当前标记切到别处。
- 后台更新期间已有匹配计数保持显示，避免每次输入都切成“查找中”。清空搜索内容、修改搜索条件或关闭查找仍及时移除对应旧高亮。
- 延续 0.1.49 的光标保护：输入、删除、粘贴、撤销和重做不会自动选中搜索结果或改变滚动位置。
- 全部替换作为一次操作处理高亮，不逐项重绘剩余匹配，保留一次撤销恢复整批修改的行为。
