# FrogShell 0.1.52 验证记录

- 编辑器增加选区搜索预填、文档缩略图，以及带差异概览的并排对比页签。对比页左侧只读，右侧支持直接编辑和撤销。
- JSON 格式化使用每级 4 个空格，结果留在编辑器中等待保存。
- 连接管理使用进程列表的圆角边框、表头与交替行背景。新增「隧道」列，按运行中数量与已配置总数显示。
- 连接管理通过外观、收藏目录和菜单回归。深浅主题测试覆盖启动、停止及在线和离线配置变更时的隧道计数。
- 打包前通过编辑分组、高亮、编辑器引擎、编辑限制、高级搜索、语法诊断、菜单和工作区 8 组回归。较广的回归中，目录展开断言和凭据测试仍有失败，端口集成测试缺少测试环境。
- Windows x64 交付包含安装版、单文件便携版和 SHA-256 校验清单。
