# 0.1.44 服务器时间确认

修改服务器时间时，确认框显示服务器、地址、环境、服务器时区和修改前后时间。生产、个人及明确的生产别名还需要第二次严重确认，提示线上服务、证书校验、日志时间顺序和定时任务风险；默认取消，不保存跳过选择。

自动校时开启时，确认框提示修改可能被覆盖。用户确认后尝试使用已有的 `date -s`；不会关闭自动校时。写入前重新探测状态，如果开启或未知的状态未获得对应确认许可，则拒绝并要求重新确认。未知状态仍需确认。没有必要的工具、缺少权限、断线或结果未知时不会自动重试写入。

确认期间锁定、断线、切换会话、关闭表单或撤销操作会取消提交。验证使用模拟命令与未启动的会话，不访问真实服务器或修改本机时钟。独立验收及打包结果以对应版本的验收记录为准。
