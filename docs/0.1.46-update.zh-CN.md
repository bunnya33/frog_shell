# FrogShell 0.1.46

上方编辑区域没有任何页签时，底部面板自动最大化。关闭最后一个文件或功能页签、将最后一个页签移出主窗口，都适用此规则；任意分屏中仍有页签时不触发。

重新打开文件、进程、监听端口或搜索结果页签时，编辑区域自动显示并还原分隔比例。底部面板仍保留当前选中的终端、端口或服务，不会为布局变化新建终端或中断进程。

搜索框清空或搜索关闭后，清理对应的命中背景、当前定位行背景、匹配计数和搜索生成的真实选区。手动选中的文本与语法错误红线仍保留；已取消的异步结果不能重新挂回高亮。

高级搜索结果记录仍可保留。关闭结果页签、结果独立窗口或取消参数窗口会清理来源编辑器的高亮；执行查找后自动隐藏参数窗口不会取消新结果。之后主动双击历史结果，可以重新定位并显示对应匹配。

清理搜索残留也避免了拖选经过旧命中位置时反复切换选区样式。普通文件和边缘滚动的卡顿另做了原生 Qt 对照，目前离线测试尚未确定全部停顿的根因，本版不宣称已消除所有拖选卡顿。

本版继承 0.1.45 的复选框、搜索高亮、搜索定位居中、拖选性能和启动及每半小时检查更新的改进。Windows 同时提供便携版、安装版及两者的 SHA-256 校验文件。
