# 右键菜单分组

0.1.30，2026-11-10。下表 `｜` 仅表示菜单分隔线，不显示组名。按语义合并，组内不插线；条件不满足而省略整个组时，不保留空组、首尾或连续线。资源显示开关移入导航栏最右侧的“更多”，其他菜单分组保留。

|---|---|
| 文件树单文件 | 下载、上传文件… ｜ 新建文件、新建文件夹 ｜ 剪切、复制、粘贴（可用时）、重命名（F2 列提示） ｜ 刷新 ｜ 删除… ｜ 属性 / 权限 |
| 文件树单目录 | 在此处打开终端、添加到目录收藏 ｜ 下载目录文件、上传文件… ｜ 新建文件、新建文件夹 ｜ 剪切、复制、粘贴（可用时）、重命名 ｜ 刷新 ｜ 删除… ｜ 属性 / 权限 |
| 文件树多选 | 下载所选项、上传文件… ｜ 新建文件、新建文件夹 ｜ 剪切、复制、粘贴（可用时） ｜ 刷新 ｜ 删除… |

文件树空白右键保留可视选择，但其菜单只作用于当前已提交目录，不带旧行的打开、下载、重命名、属性、删除。草稿或无有效绝对路径元数据的行不生成操作菜单。普通 POSIX 文件名含换行等字符，不因收藏路径规则被禁止既有下载、重命名、删除；收藏入口仍单独遵守收藏的路径规范。目录原来两个相同 callback 的下载入口合并为「下载目录文件」。新建、上传和行操作继续捕获具体路径值；菜单重命名不随嵌套菜单期间的选择变化改投目标，确认后仍核对原 session 和凭据代次。

剪切、复制、粘贴分别显示 Ctrl+X、Ctrl+C、Ctrl+V；空白菜单不显示剪切或复制，单项/多选仍保留原有效性检查与在线条件。删除独立分组，单项属性放在底部；顺序不改变目标捕获和操作语义。`..` 只导航，无文件菜单。撤销仅限会话内符合条件的文件操作；删除和覆盖不可撤销并阻断该批撤销，详见《0.1.27 资源操作设计》。

0.1.30 粘贴项仅在剪贴板含可接受的本地普通文件/目录，或同服务器有效剪切记录时显示；文本、网页链接、符号链接、伪造/过期令牌及准备中/失败的远端复制均隐藏该项。菜单打开期间随剪贴板或连接状态实时显示/隐藏，目标仍是打开菜单时捕获的目录。状态检查与实际粘贴共用只读前置判断，不读文件正文、不请求下载或 SSH。

“更多”使用现有图标和真实 QMenu/QAction，每次 aboutToShow 从当前视图同步两项 checked，不缓存旧状态。隐藏文件仍写原 QSettings 偏好，修改时间列沿用原显隐与列宽逻辑；重置设置、关闭/重开菜单不丢失视图状态。眼睛/日历时钟图标在左，勾选在右，保留鼠标、键盘和无障碍语义。

同服务器内部拖动可将真实文件/目录移到展开的子目录、其他目录，或通过顶层 `..` 移到当前目录的父目录。`..` 仍不能作为拖动来源、本地上传或剪贴板粘贴目标。落到原父目录属于合法 no-op：显示正常 Move 光标、清除目标预览和底部提示，释放接受手势但不弹确认、不建任务/历史、不写远端。混选只对需要移动的项目确认和提交。0.1.32 起，落点恰好等于任一选中来源目录自身时，整次手势同样是 no-op，混选其他项也不会移入该目录。严格后代、链接、草稿、失效来源与跨服务器仍拒绝；剪贴板自身限制不变，实际移动保留原确认和撤销规则。

同名冲突按操作显示“复制/移动/上传目标已存在”，取消按钮统一为“取消”，默认与 Esc 都取消。复制/上传保留“替换文件”“保留两者”和应用到本批次；移动不允许替换，也不显示无效的批次勾选。保留两者在扩展名前编号：`install (1).sh`、`archive (1).tar.gz`；目录 `folder.name (1)`、隐藏名 `.env (1)`、无扩展名 `file (1)`。已占用候选继续递增，仍遵循原不覆盖提交、编辑路径锁与撤销保护，Windows 虚拟导出重名显示也使用该规则。

资源树文件、目录、多选和空白菜单采用紧凑矢量图标。仅此 FileContextMenu 定制绘制，保留真实 QMenu/QAction 的事件、焦点、无障碍、checked 状态和原有回调目标，不引入按钮表或通用菜单框架。单文件菜单移除“打开文件”，保留原 itemDoubleClicked 双击打开；资源树没有新增 Enter 打开快捷键。菜单内的 Enter 仍由 Qt 激活当前动作。

基础尺寸为逻辑像素，随 UI zoom/DPR 绘制：最小宽 248，长文字或快捷键可增宽；外描边 1、四周 padding 4、外圆角 6；正文 Microsoft YaHei UI/Segoe UI 13px normal；行高 29、水平 padding 10、图标槽 20、图标 18、槽后 gap 9。图标线宽 1.7、透明度 .88；hover 覆盖 action 行并使用 2px 内圆角，保留外侧留白。分隔线 1px、上下 margin 3、左右 margin 6。右侧 18px 槽内居中绘制 14px 勾、线宽 2；快捷键右对齐、透明度 .72。隐藏文件和修改时间项左侧分别保留眼睛、日历时钟图标，右侧独立显示真实勾选状态，F2/Ctrl 提示不重复注册快捷键。

浅色使用白底、#1f2328 文字、#8c959f 外框、#d0d7de 分隔线、#eaeef2 hover；暗色使用 #21222c 底、#f8f8f2 文字、#555c73 外框、#44475a 分隔线和 hover。仅此菜单启用原生单列滚动，超出屏幕时可通过上下箭头及键盘到达全部动作，不自动分两列。真实 offscreen 截图与像素、输入回归见《0.1.28 验证记录》；其他菜单保留原样。

F2 保留文件视图现有 QShortcut 的单一注册，菜单使用 `重命名\tF2` 作为 Qt 列提示。连接目录子项仍使用共享收藏菜单，不含父级编辑/删除连接动作；混选连接和目录仍要求仅选连接再批量操作。移除收藏只移除本地入口，无远端删除确认。服务 template/demo/busy/CanReload、自启状态限制、端口 busy/运行删除确认、传输 nativeDrop 重试限制及原取消/速率行为均保留。

0.1.25 只改变终端菜单分组，Ctrl+C、PTY 字节与剪贴板行为继续保留；清屏与中断分别为显示和控制。0.1.26 的清屏改为零 PTY 输入、保留当前完整可见软行和原光标坐标，清其他主屏输出/历史，上方留空白；备用屏或软行跨入历史时禁用并提示。不承诺识别硬换行命令语法，详见《终端清屏与切屏》。关闭终端仍直接结束对应会话，文件关闭仍保留原保存保护。仅收回一个窗口动作的浮窗 ActionsContextMenu，以及 Qt 编辑正文标准菜单保持原样，不增加孤立分隔线。
