# 0.1.44 工作区布局

新建服务器工作区默认最大化终端。打开或激活文件、搜索结果和内置系统页面时显示编辑区；用户之后可以继续手动最大化终端。

每个服务器分别记住已打开的进程和监听端口页、活动系统页、终端显示状态和分隔比例。重新打开工作区时恢复这些系统页；普通文件页不会持久化。独立窗口中的系统页在重建工作区时停靠回主窗口。设置重置会清除保存的布局。

服务器状态卡将运行时间放在首行，并紧凑显示 CPU、内存和磁盘。网络接收与发送使用不同颜色及实线、虚线区分。网卡下拉列表更新时保留选择，并避免列表未变化时重建，以减少弹窗闪烁。

验证结果见 [0.1.44 验证记录](FrogShell-0.1.44验证记录.md)。
