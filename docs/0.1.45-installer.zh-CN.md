# FrogShell Windows 安装包（0.1.45 起）

每个 Windows 版本同时提供 `FrogShell-<版本>-portable.exe`、`FrogShell-<版本>-setup.exe` 和包含两个 EXE 的 `SHA256SUMS`。安装器将经过验证的 portable EXE 原样安装为 `FrogShell.exe`；它继续使用现有便携启动器和自动更新器。安装器与应用均无需管理员权限。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\FrogShell`；开始菜单快捷方式默认创建，桌面快捷方式可选。安装完成后可勾选启动，默认不启动；静默安装不启动。

升级或卸载前，请从系统托盘退出 FrogShell，先保存草稿并完成或取消传输。安装器不会强行关闭应用；如果文件正在使用，请退出后重试。卸载不会主动删除 RabbitShell/FrogShell 的配置、连接、凭据、缓存或其他用户数据。安装程序不会注册服务、自启动或文件关联。应用原地自更新后，Windows 卸载列表中的版本仍可能是最后一次安装器的版本；应用“关于”显示实际运行版本。

## 打包

先按原发布流程构建并验证 portable，使用可信的 SHA-256 固定输入。需要 Windows、Inno Setup 6 的 `ISCC.exe` 和 Python 3。例子（在项目根目录的 PowerShell 中）：

```powershell
$version = '0.1.45'
$portable = "dist/FrogShell-$version-portable.exe"
$hash = (Get-FileHash -LiteralPath $portable -Algorithm SHA256).Hash.ToLowerInvariant()
./scripts/package-installer-windows.ps1 -Version $version -PortableExe $portable -ExpectedSha256 $hash -Compiler 'C:\path\to\ISCC.exe'
py -3 scripts/verify-installer.py --setup "dist/FrogShell-$version-setup.exe" --portable $portable --version $version --expected-sha256 $hash
```

`-Version` 可省略，此时读取 CMake 项目版本；若指定则必须一致。可通过 `-OutputDirectory` 指定输出目录，已存在的同名 setup 不会被覆盖。打包脚本检查 portable 的产品版本和可选 SHA-256；本地静态验证检查两个 PE 版本、setup 图标与 portable 摘要。静态检查本身不证明安装器内的压缩载荷与输入一致；这一点由 CI 解包安装后的逐字节哈希比较验证。

发布工作流保留原有 Qt、TLS、目录包与 portable 检查，完成后构建安装器。优先使用 runner 已安装的 ISCC；缺失时从 Inno Setup 官方 GitHub release 下载固定版本 6.2.2 并核对 SHA-256 `8117d10d00a2ad33a1390978ea3872861c330e087914410a6377b22c4c5b8563`，以官方 `/PORTABLE=1` 模式在 GitHub 临时 runner 的临时目录静默准备编译器。此模式不创建编译器卸载登记、快捷方式或文件关联，不要求管理员权限。来源：<https://github.com/jrsoftware/issrc/releases/tag/is-6_2_2>。

兼容性基线为实际测试过的 Inno Setup 6.2.2，`ArchitecturesAllowed` 和 `ArchitecturesInstallIn64BitMode` 均使用该版本支持的 `x64`。本地在任务专用 `.tools` 目录实测了官方 `/CURRENTUSER /PORTABLE=1 /NOICONS` 静默编译器准备过程，退出码为 0；检查的 8 个编译器卸载登记与 `.iss` 关联位置均未变化，未生成编译器卸载程序。所得 `ISCC.exe` 的 SHA-256 为 `29856cf82d9a993afd7da8f99fb89f24d65ce3271c5b042cf387257c8fd7660f`。当前安装脚本使用历史 0.1.44 portable 作为兼容性夹具完成了零警告编译、PE 版本/图标检查及无安装解包后的载荷哈希比较。此夹具不属于 0.1.45 发布包，也不代表产品安装/卸载或其他版本编译器已经实测；0.1.45 的正式产物需以最终 portable 重新打包验证。

`verify-installer.py --ci-smoke` 仅在 `GITHUB_ACTIONS=true` 时运行，若发现现有默认安装路径或同 AppId 的卸载登记则中止。CI 使用临时安装目录和临时配置，禁止快捷方式，核对安装文件与 portable 哈希相同，并用最小 PATH 验证 `--version`；使用已安装程序和隔离配置在 offscreen 模式启动 manager/demo，只终止测试拥有的进程；随后静默卸载，检查卸载登记和安装文件已移除、注入的测试配置及安装目录内未知文件未变。此测试会在临时 runner 的当前用户注册表创建并卸载产品登记；不用于用户机器。本地验证不运行实际安装或卸载，不能代替 CI 冒烟结果。
