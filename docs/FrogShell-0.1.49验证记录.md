# FrogShell 0.1.49 验证记录

## 范围

查找开启时的编辑选区保护、GitHub 更新下载恢复、独立于检查结果的手动下载链接。保留 Scintilla 编辑器、两套主题及现有更新安装和未保存保护。

## 问题复现与验收方法

旧版代码上新增的两项查找回归均失败：修改后光标从编辑位置跳到下一处搜索结果，以及查找等待期间创建的用户选区被覆盖。修改后检查输入、选区保持、直接编辑搜索命中项和显式查找跳转。

下载使用隔离的环回 HTTP 服务检查：传输中断后的 Range 续传、公开附件 API 入口、每次入口请求的刷新标记、HTTP/1.1 恢复、过期 CDN 跳转、未发送 EOF 的完整文件、错误范围/长度/摘要、重试等待、取消、总时限和对象销毁。未放宽下载来源校验，不使用任何第三方镜像。

手动下载链接在尚未检查更新及检查失败时均可见，分别检查关于页和更新设置页。使用 URL 拦截器验证只打开固定 GitHub Release 页面，不实际打开浏览器；检查软件锁定时不会打开外部链接，以及 Dracula / GitHub Light 的截图。

公共网络诊断程序 `frogshell_update_probe` 只在明确调用时运行，不加入常规 CTest。它使用与产品相同的更新客户端、临时下载目录，不读取应用配置或 GitHub 凭据、不安装更新。`--recover` 模式对首次下载请求注入一次 503，随后真实验证匿名 GitHub API 备用入口和附件下载。输出只含主机、状态码、字节数、耗时和摘要，不输出签名地址。

## 发布验收

本地 9 组测试共 268 项通过、0 失败、0 跳过：更新下载 70、编辑器高亮/选区 18、编辑器引擎 8、高级搜索 20、语法诊断 35、编辑分组 34、更新界面及退出保护 24、日志 6、外观 53。深浅主题手动下载链接的截图已复核。

真实公共网络中，普通下载与首次 503 后的匿名备用 API 下载均完整获取 0.1.48 附件，大小为 23,147,008 字节，SHA-256 均为 `9ae070bbf698deabe5394c91b814d0cc3e8f651112420fa70ec330fcc10b9e2c`；备用入口及后续 CDN 请求使用 HTTP/1.1。该次实测不能保证其他网络下的下载速度或可用性。

测试、修复前后的复现报告和公开网络诊断保存在 `test-results/0.1.49/`，汇总到该目录的验收报告。

Windows Release 工作流从同一标签提交构建便携版和安装版，执行隔离启动与安装/卸载检查。发布后核对公开附件、SHA256SUMS、源提交和工作流验收报告。

## 边界

本机首次公共网络诊断可完整下载 0.1.48，未复现用户网络下的实际停顿，因此不将任何一个网络原因认定为该次故障的唯一根因。已针对代码中可验证的恢复缺陷和连接结束依赖补充修复及回归。未连接或修改用户的远程服务器，未替换用户正在运行的程序。
