# FrogShell 0.1.47 验证记录

## 范围

主线程完成更新下载的超时、重试、续传和提示修改；同时纳入用户确认的官方 Scintilla 5.5.7 编辑器迁移，没有委派开发代理。构建为 Windows x64、Qt 6.8.3、MSVC v143 Release；依赖安装和运行库部署均使用项目内目录。

## 本地检查

使用独立配置、离屏 Qt 窗口、环回 HTTP 服务和合成安装包，不连接真实 SSH 或操作服务器。测试中的剪贴板是离屏平台内的测试数据；打包启动使用临时用户目录，不读取日常连接配置。

更新下载检查包括：中途断线后 Range 续传、刷新 CDN 跳转、强 ETag、服务器忽略 Range 时重置文件、错误范围/长度/摘要拒绝、临时与永久 HTTP 错误分类、Retry-After、三次重试耗尽及本次运行内手动续传、重试等待期间取消/变更源/析构、总时限不因重试重置、下载与查询各自的无数据时限。

更新界面覆盖重试提示、继续下载、取消等待、关闭关于窗口后继续下载、应用锁阻止更新、重启前保护草稿、保存失败/取消退出及准备安装文件的生命周期。

编辑器回归覆盖原生输入与 UTF-16/UTF-8 换算、锚点和撤销、语法诊断、普通和高级搜索、高亮清理、主题、页签分组/分屏/浮窗、菜单、工作区及应用锁。迁移前后的计时与 25 轮对象/内存验证见 `editor-scintilla-migration.zh-CN.md`；本次没有将编辑器迁移扩展为额外的远端功能。

最终测试日志保存在 `test-results/0.1.47/`；构建日志为 `build-scintilla/release-0.1.47-build.log` 和 `build-scintilla/update-final-build.log`。

下载核心 67 项、更新界面 23 项、自更新安装保护 24 项均通过。网络夹具的短时限在并发编译中暴露时序依赖，已为测试留出实际传输窗口，保留原有断言和产品时限。

界面复查发现测试行复用了相同模拟服务器/路径：前一行的 800 毫秒自动草稿保存会让下一行停在“恢复草稿”确认框。搜索测试现逐行使用独立临时数据目录，外观测试仅清理自己的临时草稿，丢弃后重开测试实际执行丢弃动作；产品草稿恢复逻辑没有修改。初次日志和临时诊断证据保留在本次测试目录；完整界面套件的复查使用 300 秒外层运行上限，不放宽搜索子进程或其他产品内的时限。

## 发布检查

同时交付便携版和安装版。目录包与便携包必须通过只使用部署 DLL 的版本、连接管理及离线工作区启动；安装版在本地做静态版本/图标/摘要检查，实际安装、启动、卸载、配置及未知文件保留在 GitHub Actions 临时环境检查。

发布后核验 GitHub 稳定版本标识、两个公开 EXE、`SHA256SUMS`、GitHub 资产摘要、嵌入文件摘要和版本，以及 Scintilla 许可、Qt Core5Compat 与 TLS 后端；另从公开资产执行隔离启动。最终公开发布验收记录为 `test-results/0.1.47/main-release-report.json`。

## 限制

断点仅保留于本次程序运行内；主动取消、重新检查、退出、总时限到达或校验失败都会清理。下载停顿 120 秒、查询停顿 15 秒，查询总时限 30 秒，下载总时限 20 分钟，最多自动重试 3 次。锁定软件会取消更新。

Windows 离屏与本机检查不能替代 Linux/macOS 的实际构建、输入法和窗口系统验收，也不能保证任意网络环境均能连接 GitHub。
