# 0.1.39 实施与验收方案

## 高级搜索

Ctrl+Shift+F 及编辑菜单的“高级搜索”捕获当前聚焦的编辑文档，包括浮窗与未保存缓冲；参数窗口固定服务器配置 ID、连接身份和完整路径。保留各编辑器已有 Ctrl+F 查找替换。

全应用一个结果容器，页签和独立浮窗之间移动同一控件；新搜索替换旧结果，切换文档或服务器不重新搜索。每个命中行只列一次，同一行的所有匹配高亮；摘要显示匹配数及行数。双击或 Enter 激活来源，必要时按原身份重开，不恢复已丢弃的未保存内容。存活文档使用跟随编辑的光标锚点并校验原行；重新打开须校验搜索快照。无法精确定位时明确提示结果过期。

搜索采用按需启动的本机子进程，不读取配置、不访问网络或远端。单次正则使用 PCRE 运算/深度限制，父进程另设 2500ms 硬超时并终止失效任务；新代次和应用锁代次校验防止旧响应写回。文本上限 8Mi UTF-16 字符，正则文档上限 256Ki 字符，搜索词 512 字符；最多 10000 匹配、3000 行、1Mi 字符上下文。触及结果上限明确标记部分结果。搜索结果不写入本地历史。参数及结果浮窗受应用锁和托盘生命周期保护。

## 端口与服务器状态

端口转发按本地端口、远端端口、上传速率、下载速率、状态排列；移除行内更多按钮，保留必要右键菜单。使用进程表的圆角大卡片、表头分隔、错行背景和紧凑行高；狭窄窗口允许横向滚动，草稿不丢失。上传使用网络发送 TX 的颜色，下载使用接收 RX 的颜色。Toggle 常态、悬停、禁用与开启状态均有可辨轨道和边界，开启为绿色。服务器状态网络卡片移至最下方，监听概览与完整表格的端口数字均使用强调色，选中行保留对比；协议颜色和粗体继续独立保留。

搜索参数窗口沿用系统标题栏。正文与底部操作区分开，底栏使用侧栏底色和单条顶分隔线，按钮至少 82×31 逻辑像素，关闭按钮常态保留边框。窄窗按实际选项宽度换行，完整显示三个选项。

## 品牌与兼容

显示品牌改为 FrogShell，集成批准的青蛙图标及新可执行文件/便携包名称。保持 RabbitShell 内部组织、应用、数据位置、凭据键、单实例、协议和 MIME 身份，已有连接、收藏、密码及界面设置继续读取。不全局替换内部命名，不修改旧交付和批准参考。

## 验收

隔离配置与离屏实际控件验证 A→B 来源稳定、新搜索覆盖、同名跨服务器区分、页签/浮窗唯一容器、双击/Enter 定位、文档修改/关闭/重开、应用锁、旧任务失效、无效/复杂正则及边界结果。实际生产控件保留暗/浅和窄宽截图。端口针对列顺序、颜色、开关、菜单和草稿做回归。完成增量构建及必要测试后交主线程独立审查；审查通过再冻结源码、新版目录包与单文件便携包，并核验 payload、隔离启动和旧产物不变。禁止 clean-first、真实服务器、用户配置、系统剪贴板及 main-* 独立证据修改。
