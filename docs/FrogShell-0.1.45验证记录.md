# FrogShell 0.1.45 验证记录

## 变更范围

- 复选框指示器由共享界面样式绘制，适配深色和浅色主题、界面缩放及高 DPI；保留标准 `QCheckBox` 的布局、键盘交互和信号。上传冲突对话框使用同一规则。
- 高级搜索结果在编辑器内显示全部匹配，并突出当前匹配所在行。具体边界与验证结果见下方测试记录。
- 自动更新在启用时启动后检查一次，此后按 30 分钟间隔检查；服务端限流期限与禁用设置仍然生效。
- 目录包和便携包默认版本为 0.1.45。目录包保留历史文档，并附带本记录。
- 本次及后续 Windows 发布要求同时提供便携版和安装版；安装版封装同一便携 EXE。本机便携版 Inno Setup 6.2.2 已完成夹具编译，正式安装包待便携包完成后构建；CI 也会验证安装和卸载。

## 实际验证

使用 Qt 6.8.3、MSVC v143 Release 构建应用和目标测试；离屏测试使用临时配置目录及合成数据，不访问真实 SSH、密码库或剪贴板。中文截图加载 Windows 微软雅黑字体。日志与截图位于 `test-results/0.1.45/worker/`。

- controls 9 通过；复选框单独在 1.5× DPI 下 3 通过，覆盖两种主题、缩放 -1/0/2、选中/未选/部分选中/禁用/悬停/焦点、标签点击与空格键。
- appearance 定向 4 通过，截图包含实际连接配置、登录口令、私钥口令、诊断、更新、服务及权限对话框。
- document search 16 通过；release update 44 通过；update UI 22 通过。
- editor highlights 首次 7 通过、2 失败：普通查找时当前行底色落在匹配的上一行，深浅主题均可复现。首次修复后仍为 7 通过、2 失败：上一行底色消失，但普通查找的当前行也没有全宽底色。证据分别保留在 `worker/editor-investigation/` 和 `worker/editor-highlights-rowfix/`。再次修复后 editor highlights 9/0、document search 16/0；截图和日志位于 `worker/editor-highlights-rowfix2/` 与 `worker/search-rowfix2/`。测试覆盖前一行、换行末尾空白、尺寸及字体变化。
- 主线程独立性能探针使用约 60.8 万字符、同字体和视口、排队绘制的鼠标选择，未修改文本或连接 SSH：普通选择平均 5.2184→0.6335 ms，p95 15.7764→1.7217 ms；1000 个 Ctrl+F 匹配时平均 6.8440→0.8781 ms，p95 10.9811→1.7708 ms。测试耗时受环境影响；证据为 `main-selection-baseline-3` 和 `main-selection-final`。
- 主线程基于 checkpoint-2 的独立 UI 探针 6/0，覆盖当前行和前一行像素、定位居中、复选框及启动检查；深浅主题截图视觉复核通过。详见 `main-final-acceptance.json` 与 `main-visual-review.json`。

源码冻结及本地目录/便携包核验另见本次发布证据。安装包将用本机编译器生成；CI 安装/卸载测试未在本机执行，公开发布由主线程负责。
