# 保存密码：交互与验收约定

2026-11-03。按用户要求增加可选的保存密码功能；本文件记录设计，实际完成和验证状态以实现记录为准。

## 用户操作

- 新建／编辑连接和登录弹窗都提供「保存密码」勾选；私钥认证对应「保存私钥口令」，SSH Agent 不需要此选项。
- 新连接默认不勾选。不保存时，凭据只用于当前会话及它的传输连接。
- 勾选并成功保存后，后续连接、断开重连、退出软件再打开都读取该连接的系统凭据，不重复要求输入。
- 编辑已有连接时不回填真实密码，用提示说明已保存；密码框留空代表保留原密码。修改服务器、端口、账号、认证方式或私钥时，不沿用旧身份的密码。
- 取消勾选并保存、删除连接配置，会清除该连接的已保存凭据。关闭表单或取消登录不等于提交修改。
- 密码失效后允许重新输入并替换，不无限重试。网络中断、服务器不可达或主机指纹拒绝不能被当成密码错误。
- 系统安全存储不可用时清楚说明保存未成功；用户仍可选择不保存并进行本次登录。

## 存储与连接边界

- 普通 JSON 仅存保存偏好，不包含密码、私钥口令或可还原的编码值。导出和复制配置不携带凭据及保存偏好。
- 凭据使用操作系统安全存储，绑定配置 ID 与实际认证身份；不同配置互不串用。新数据目录下的测试使用随机配置 ID。
- 已打开工作区不因编辑配置而自动改变远端身份。同身份更新密码后，断开重连使用新凭据；身份发生变化时，提示先正常关闭旧工作区，再打开新身份，避免把旧草稿或排队传输发送到另一服务器，保持工作区唯一性。
- 旧工作区、延迟完成的认证或传输连接不能恢复用户已经取消保存或删除的凭据。
- 运行时登录弹窗更改保存偏好后，同步连接管理配置；应用重启后继续生效。
- 空私钥口令与尚未提供口令是不同状态；使用明确的状态，不仅用字符串是否为空判断。
- 后台存储回调不得阻塞界面，也不得在所属窗口销毁后访问它。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 不勾选，关闭工作区后重新打开 | 再次输入，系统凭据库不新增该连接密码 |
| 勾选，连接成功后重新连接 | 自动使用保存密码 |
| 勾选后退出、启动新进程 | 自动读取同一配置的密码 |
| 编辑名称、目录或分组，密码留空 | 已保存密码保留 |
| 修改账号／主机／端口／认证身份 | 不向新身份发送旧密码 |
| 取消保存或删除配置 | 凭据删除，旧工作区不能重新写回 |
| 保存错误密码后重新连接 | 允许输入正确密码并替换，无自动重试循环 |
| 主机指纹拒绝或网络断开 | 不误清理有效保存密码 |
| 既有断开工作区中更新密码再连接 | 使用新密码，同配置仍只有一个工作区 |
| 登录成功后启动文件传输 | 传输连接可正常认证 |
| 复制或导出连接 | 不复制密码或保存偏好 |
| 系统库失败／锁定／不可用 | 有明确反馈，无明文回退，无静默假成功 |

自动验证只使用本机 SSH fixture、隔离目录、随机连接 ID 和合成密码。操作系统真实存储至少覆盖写入、另进程读取、更新与删除。Windows 实测和其他系统未实测的边界分别记录。
