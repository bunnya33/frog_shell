# FrogShell 0.1.39 验证记录

本版新增当前文档高级搜索，调整端口转发及服务器状态界面，并将可见名称和应用图标更新为 FrogShell。具体行为见 [实施说明](0.1.39-implementation.zh-CN.md)。

## 使用与兼容

编辑文档聚焦时按 Ctrl+Shift+F，或从编辑菜单打开高级搜索。参数窗口固定来源服务器与路径，搜索包含未保存缓冲；现有 Ctrl+F 查找替换不变。搜索结果仅有一个容器，可在编辑页签与独立窗口之间移动。切换文件不改变既有结果，新搜索替换结果。每个命中行只列一次，同一行多个命中全部高亮；双击或 Enter 返回原来源并定位。

存活文档使用跟随编辑的锚点并校验原行；来源已关闭时按服务器配置 ID、连接身份和路径重开，并校验快照。结果过期时提示重新搜索，不静默定位错误内容，不恢复用户已丢弃的草稿。应用锁覆盖搜索参数及结果浮窗，锁定时禁止导航。

本机后台子进程执行搜索，不访问服务器或配置。正则单次运算与深度受限，父进程设置 2500ms 硬期限；结果有匹配数、行数和上下文上限，旧任务和锁代次不能回写。普通文本上限 8Mi UTF-16 字符、正则文档 256Ki 字符、搜索词 512 字符；最多 10000 匹配、3000 行和 1Mi 字符上下文。达到上限会明确显示部分结果。

端口转发表按本地端口、远端端口、上传速率、下载速率、状态排列；开启轨道绿色，上传与下载沿用网络 TX/RX 配色。监听概览及完整表格的端口数字使用强调色，协议保留独立颜色和粗体。网络状态卡片在侧栏底部。

主程序为 FrogShell.exe，窗口、托盘和便携启动器使用同一青蛙图标。内部组织/应用名、数据目录、凭据、协议、MIME 与单实例身份继续使用 RabbitShell，兼容已有连接、收藏、密码和本地偏好。上传暂存与会话重连规则不变，不向服务器安装程序。

## 本轮回归

Windows x64、Qt 6.8.3、MSVC Release，使用隔离配置及 offscreen 实际控件。最终定向结果（含 init/cleanup）：搜索 11/0、端口 10/0、进程与监听 10/0、托盘与退出保护 8/0，全部零跳过。搜索覆盖来源固定、唯一容器、修改后定位、关闭重开、取消过期任务、正则边界、真实硬期限下 UI 心跳及应用锁；端口覆盖失败删除后的第 0–4 列状态通知和草稿保护；监听覆盖列宽、缩放及暗浅 mini/full 选中数字的实际绘色。

独立公开接口 probe 最终 8/0，另覆盖主窗和浮动编辑器的真实 Ctrl+Shift+F 入口、跨服务器同路径、图标各尺寸透明度及端口布局。便携参数测试 2/0，保留历史版本的固定校验规则。早期选中色精确像素断言的失败记录保留；最终检查允许小字号抗锯齿造成的最多 12/255 色差，排除背景色与普通文字。

实际暗浅/窄窗截图位于工作区 test-results/0.1.39/search-final、ports-final 和 process-final；独立 probe 的报告属于 main-* 证据。源码冻结、目录 inventory、便携 payload 逐文件哈希、双 PE 图标和隔离启动记录由包外交付报告保存。本轮不访问真实服务器、用户配置或系统剪贴板；未实测 macOS/Linux 构建、原生桌面合成和真实服务器环境。
