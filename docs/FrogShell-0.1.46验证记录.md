# FrogShell 0.1.46 验证记录

## 范围

编辑区域清空后自动最大化底部面板，并在重新显示上方内容时还原；覆盖多个编辑分组、文件浮窗、系统页签、搜索结果以及按服务器保留布局。补充搜索清空和关闭后的高亮生命周期检查，以及快速往返拖选的长尾延迟调查。实现与测试由 Terra 极高完成，主线程审查验收并发布。

## 本地验证

Terra 极高完成实现和同库回归，主线程独立审查变更、核对源码及库哈希并验收实际 QWidget 布局。证据位于 `test-results/0.1.46/`，测试使用隔离配置和离线样例，没有连接真实 SSH、使用用户凭证或操作服务器。

| 检查 | 结果 |
| --- | --- |
| 编辑器高亮与选择所有权 | 11 通过，0 失败 |
| 高级搜索、取消及延迟激活 | 20 通过，0 失败 |
| 工作区布局定向回归 | 10 通过，0 失败 |
| 编辑分组、迁移与浮窗 | 17 通过，0 失败 |
| JSON、YAML、TOML 等语法诊断 | 35 通过，0 失败 |
| 主线程独立布局及搜索验收 | 4 通过，0 失败（含初始化、清理） |

主线程检查两套主题的实际渲染：关闭分屏中的一个文件仍保留编辑区，关闭或移出最后一个页签才最大化；激活浮窗不显示空白主编辑区；重新停靠或打开文件后恢复原分隔尺寸，过程没有新建终端或 SSH 会话。搜索清空、Esc 关闭后，命中背景和搜索生成的真实选区均清理，手动选区和 JSON 错误波浪线保留。

完整语法回归首次发现 worker 构建覆盖 `CMAKE_CXX_FLAGS` 时遗漏 MSVC `/EHsc`，导致 toml++ 模式与冻结的 0.1.45 不同，出现 3 项失败。恢复异常处理参数并重编所有相关库后为 35/35；正式发布使用标准 CMake/MSVC 配置。早期失败日志和旧快照保留，不作为最终交付库。

## 拖选性能与限制

确认并修正了一条额外样式切换路径：关闭高级搜索后残留的命中位置会使手动往返选择反复启停搜索选区样式。清理后对应对照中的样式切换降为零。

同时对比了原生 Qt、CodeEdit 和完整工作区，覆盖普通中文行、长行、同屏往返、边缘自动滚动及空闲/编译负载。普通行空闲合成输入中，完整工作区的绘制间隔接近原生 Qt；但长行和边缘滚动出现过明显长尾，结果受运行次序及负载影响。离屏测试未确定用户所述普通文件持续停顿的完整根因，不能据此宣称全部拖选卡顿已消除或达到 VS Code 的流畅度。没有增加缺乏证据的同步重画或输入节流。

## 发布验证规则

Windows 同时交付便携版与安装版。CI 必须通过目录包及便携包启动，并在临时云端环境验证安装、启动、卸载及配置保留后，才允许发布。主线程另行下载公开的两个 EXE 和 `SHA256SUMS`，核验资产摘要、嵌入版本、TLS 后端、隔离启动及对应 CI 安装证据；发布后的最终结果记录在 `main-release-report.json`。本地测试不代替云端安装验证。
