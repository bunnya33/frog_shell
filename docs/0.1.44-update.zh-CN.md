# FrogShell 更新说明

更新固定检查公开仓库 `bunnya33/frog_shell` 的最新稳定 GitHub Release。旧配置中的仓库用户和名称不再决定更新来源；从其它旧来源迁移时，旧来源的检查时间也不沿用。设置中的自动检查默认开启，可以关闭；自动检查至多每 24 小时一次，长期驻留时每小时判断是否需要检查。手动检查仍受服务端限流约束。

发现新版本时托盘图标切换为张嘴青蛙，右键菜单提供更新入口；没有可用更新时显示原有图标。Windows x64 单 EXE 点击后下载所选版本，验证 SHA-256，后台准备安装，再显示现有的退出确认。未保存文件、传输和应用锁仍由原流程保护；取消确认、保存失败或锁定不会继续安装。下载和准备期间菜单显示状态，支持取消；下载或准备失败后可重试。不会自动下载或安装，直到用户选择更新。

目录运行、其它平台以及发布缺少可验证安装包时，菜单会打开关于窗口，提供发布页或已校验文件位置供手动更新。发布说明以纯文本展示。已准备的安装由现有 selfupdate 负责身份校验、替换、启动确认和必要时回滚，应用不会另行覆盖可执行文件。

稳定 `vX.Y.Z` tag 触发 Windows 工作流：构建目录和单 EXE、执行打包检查、生成 `FrogShell-X.Y.Z-portable.exe` 与 `SHA256SUMS`，然后创建 GitHub Release。清单中每行使用 SHA-256、两个空格和精确文件名；更新核心优先使用 GitHub 提供的资源摘要，否则验证清单。手动触发默认只上传 CI artifact，显式选择发布才创建 Release。
