# RabbitShell 0.1.38 验证记录

本版完善终端列表、编辑器查找替换、分类设置、进程和监听端口筛选、端口映射与本地隧道速率，并增加托盘隐藏、锁定和统一退出。实现范围与验收细则见 [实现说明](0.1.38-implementation.zh-CN.md)。

## 实现边界

- 查找支持大小写、全字、正则、匹配高亮和替换；正则运行在后台并设有复杂度与输入规模上限。高亮不修改文件内容。
- 监听端口使用现有采集连接，采集异常保留旧结果并标记状态；TCP 可创建或定位映射，UDP 不支持 SSH TCP 转发。监听端口本身不提供未经可靠测量的速率。
- 转发速率只统计本工具本地成功转发的字节，按规则汇总，不代表服务器端口的总流量。没有额外的 SSH 连接或远端监控程序。
- 有托盘时主窗口关闭为隐藏，恢复原先可见的所属浮窗；托盘不可用时回退到退出确认。显式退出保留保存、放弃和取消选项，并重新检查状态。应用锁仍需先解锁。
- 既有上传同目录临时文件和原子替换规则、SSH 断线及重连边界保持不变；不依赖在服务器安装代理。

## 本轮验证

Windows x64、Qt 6.8.3、MSVC Release；使用离屏控件、隔离配置及本机回环夹具，未连接真实服务器。针对性 Qt 测试覆盖查找及设置暗浅截图、端口映射和草稿、终端分组与重连、监听状态及列宽、菜单、托盘和退出保护，结果见工作区 `test-results/0.1.38/`。保存失败回归使用不可写编辑控件模拟；双工作区保存完成回归使用离线演示工作区及异步完成通知。

生产隧道 `randomDuplexMultipleRules` 在私有 SSH 回环夹具上通过，覆盖双规则、并发、空闲归零和重启，夹具记录一条 SSH 连接，结束时无活动连接或转发，未调用 exec、SFTP、PTY 或 shell。独立 probe 另验证非对称双向字节计数。原生系统托盘桌面合成、macOS / Linux 和真实服务器网络环境未在本轮实测。
