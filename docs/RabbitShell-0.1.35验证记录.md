# RabbitShell 0.1.35 验证记录

2026-11-11 · Windows x64 / Qt 6.8.3 / MSVC Release。功能及保护边界见[应用锁与收藏终端组](RabbitShell-应用锁与收藏终端组.md)。

- 收藏：离线与隔离 SFTP 响应覆盖重复复用、最近正文焦点、组内拆分、显式新增、别名与移除、最后关闭、已结束终端重开和身份/请求过期。既有私有 SFTP + bash PTY 测试确认新组在收藏目录启动，另一个组的 cwd 不变。
- 应用锁：真实主窗、工作区父对象下的浮动编辑窗、后续普通窗、已有/后续模态、锁中关闭、跨窗解锁与单实例唤起。QWindow 路径验证键盘输入和按钮；底层控件隐藏且禁用，可访问状态、快捷键及拖放均检查。验证锁前关闭确认不丢草稿，编辑文档/终端对象保留。
- 密码：异步校验、错误密码与退避、换密/关闭认证、三种设置对话框在 KDF 中取消、重复锁屏失效旧校验、写入失败、标记丢失/损坏与重置保留。启动顺序检查锁前不构造主窗，凭据读取及新会话启动被拒绝。
- 私有 loopback：1 MiB 上传锁中继续推进，解锁后原服务 worker 仍能提交并完成操作。两个夹具仅监听本机，不运行真实系统服务。
- Windows 原生消息：隐藏接收窗 WTS 注册成功；向其发送模拟锁屏、控制台/远程断连及休眠消息均触发锁定。没有实际锁定电脑。macOS 和 Linux 通知代码已接入，未在对应系统实机验证。
- 真实生产控件截图：暗浅两主题，启动锁、工作区锁、浮动编辑窗锁、设置安全区，以及 800×480 / 144% 应用缩放；为客户区截图，不含系统标题栏。

17 个受影响套件全部通过，QtTest 合计 357 通过、0 失败、31 跳过（含初始化和清理）。跳过项需要单独的 SSH/SFTP、服务、端口、原生拖拽或 Windows 通知夹具；锁的 loopback、原生通知以及收藏 PTY 已另行运行。没有用测试替代真实服务器或用户配置。发布产物逐文件校验与隔离启动结果记录在包外的 0.1.35 最终报告。

打包烟测发现并修复 Windows 中文 --data-dir 被窄环境接口按系统代码页误解、转到乱码目录的问题；Windows 改用宽字符环境接口，保留 CLI 路径优先级。单文件烟测使用含中文和空格的私有目录，锁定启动必须记录 LockStartup 且没有 MainWindowStartup；不能用 ASCII 路径通过代替。
