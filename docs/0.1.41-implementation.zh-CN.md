# FrogShell 0.1.41 实施说明

## 本地端口转发

开启状态以 SSH 就绪和本机真实监听成功为准。Windows 同时使用独占绑定与 IP Helper 的有界 TCP 监听快照，阻止已有 wildcard/reuse 监听造成的假成功；不同具体地址的同号端口仍可分别使用。检查失败显示准确原因，不改变其它进程的监听。

沿用 `tunnels.json` 的 `autoStart` 保存启用意图：首次手动开启成功才记住，手动关闭清除；断线、退出和自动恢复失败保留意图。重新连接恢复已记住规则，不抢当前页签，自动恢复失败按批次提示一次。保存失败明确显示未保存，不声称下次会恢复。

## 配置、日志和本机空间

设置可选择数据目录并迁移已有配置，保留 RabbitShell 内部持久身份、连接、密码和应用锁兼容性。迁移通过预检、独占锁、复制校验与最后提交切换，取消或失败保留原配置。需要重启的路径变更走原有退出保护。

日志默认关闭，可在设置开启并指定目录。portable 启动器不再自行写 child exit 日志；由子进程按同一日志设置记录。设置页后台统计本机配置/缓存及白名单日志的逻辑大小，按需刷新，不访问服务器，不跟随链接；扫描有数量和深度上限，部分统计明确标识。

“清理缓存”先预检，再由用户确认。只处理已识别、未被使用的缓存批次与白名单日志，保留配置、草稿、known_hosts、未知文件、活动批次及引用中的缓存。日志运行时还保留当前和轮转日志。忙碌期间禁用目录迁移和日志路径变更，离开页面或锁定取消未提交操作。Windows 使用固定文件句柄和身份复核；其它平台目前提示不支持安全清理，并且不删除。

## 编辑与控件

JSON、JSONC、XML、YAML、TOML 使用本地后台解析，错误用红波浪和就地提示表示。只诊断语法，不作为完整 schema/业务验证；诊断有 1 Mi 字符上限与过期结果检查，不上传内容。切换主题、查找高亮和滚动不会清除仍有效的诊断。

文件编辑上限默认 5 MiB，可设置 1–256 MiB；读取过程中增长仍受限制。调低限制不阻止已打开文档保存。保存冲突校验使用流式 SHA-256 并有 512 MiB 绝对边界；队列保留有限预算，原同目录临时文件和原子替换规则不变。

全应用下拉和数字/日期时间控件只有点击聚焦后才允许滚轮修改；程序聚焦、Tab 和点击别处不能误改。未启用时滚轮交给页面滚动，下拉弹层保留原生列表滚动。

## 服务器时钟

footer 显示服务器日期时间，秒数在本机用单调时钟推算，约 60 秒远端只读校准。使用独立 command-only 服务连接，主 Files/PTY 不执行时钟命令。点击可打开设置面板，真正修改需再次确认；不隐式关闭 NTP，不安装工具，不自动重放结果未知的写操作。锁定、断线、身份变更和关闭撤销待执行修改，并关闭确认框和面板。

## 下载反馈的边界

“双击目录出现下载任务”在隔离 UI 回归中未复现，不宣称修复了未知根因。新增目录/父目录/嵌套目录导航、菜单取消零下载回归，以及受总日志开关控制的常量来源事件；不记录原始服务器路径或文件正文。详见本版本下载诊断说明。

本轮没有接入关于、在线更新或新树形终端原型。验证和交付索引见同版本验证记录，旧版本包与独立审查证据保留。
