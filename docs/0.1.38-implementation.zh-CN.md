# 0.1.38 实现与验收

- 终端管理以终端连续行显示，同一分屏组通过缩进和连接线区分，不显示组标题；保持组关系、焦点、历史、重连及单终端隐藏，最大宽度为 450 逻辑像素。
- 编辑器查找面板覆盖编辑区右上角，支持大小写、全字、正则、计数、前后查找以及展开替换；替换支持保留大小写、单项和全部，匹配高亮不修改文档。验收无效正则、零长度、Unicode、捕获组及撤销。
- 主题放在设置菜单的二级菜单中；设置窗口按外观与缩放、内容字体、安全、诊断、重置分类，保留现有设置及鼠标滚轮焦点保护。
- 进程与监听端口页筛选框靠左、数量紧随其后；监听端口本地筛选，保留刷新状态，列顺序为协议、地址、端口、进程、PID，并使用进程表格视觉规范。TCP/UDP 用不同的加粗颜色区分。
- 监听采集失败时保留旧结果并标记“已过期”，截断结果标记“部分”，详细原因显示在提示中；托盘与端口映射菜单沿用统一的圆角菜单。
- 监听项可创建或定位 TCP 端口映射，通配地址映射到对应回环地址，不自动启动，不覆盖草稿。UDP 转发不可用并说明原因。服务器监听端口没有可靠的低开销逐端口速率来源，因此不显示估算值。
- 端口转发列表显示本地实际转发的上传和下载速率；按成功转发的字节计算，多个连接按规则汇总，停止与重连清零，不产生额外 SSH 连接或远端采集。
- 工作区关闭对话框分行显示服务器身份和非零风险数量，保留保存或取消的选择。主窗口关闭时有可用托盘则隐藏并保留原本可见的浮窗与模态窗口状态；托盘的“显示面板”恢复窗口，“锁定”在启用应用密码后可用，“退出”统一确认并安全关闭。锁定时先解锁，托盘不可用时回退到退出确认；确认期间状态变化须重新确认。

验收使用隔离配置、离屏控件与本机回环；覆盖查找替换、终端分组、设置、筛选和端口映射、双向及并发转发速率，并检查暗色与浅色显示。保持现有远端文件写入和连接生命周期规则。
