# 目录收藏

0.1.24，2026-11-10。

资源树目录右键「添加到目录收藏」；当前目录可在列表空白处右键添加。收藏卡片在资源树下方，高度可拖动分隔条调整。名称、路径两列可调宽，完整文本可悬停查看。拖动收藏行在插入线前后排序，只接受同一列表内部移动，不会形成父子目录，也不会上传文件。

0.1.35 起双击或 Enter 打开收藏会切到资源管理并定位，按需创建以收藏名称命名的独立终端组；同一服务器、同一收藏重复打开会激活原组最近聚焦的活动终端，不新增、不发送 cd、不重启或中断进程。组内拆分和组头「在组内新建终端」归入该组；顶部全局 + 仍创建独立组。右键「打开目录」只定位且保留当前底部页签；「在此处新建终端」明确新增独立终端，不改变浏览目录及侧栏页签。目录先经 SFTP list 成功验证，空目录也有效；不存在或权限不足时保留收藏、显示原因，不回落主目录或假报成功。

连接管理保留名称、地址、用户、环境、状态五列。带收藏的连接可展开显示名称与路径；展开本身不连接服务器。目录子项的打开行为复用对应工作区，没有工作区时连接后再验证目标。F2 不对目录子项执行服务器重命名，子项菜单也不提供删除连接。混选连接和目录时，批量服务器操作要求先仅选择连接行。刷新按稳定 ID 复用节点，保留仍存在可见项的展开、选择、当前项和滚动位置。

别名可重复，留空恢复目录末段名；根目录显示「根目录」。别名不修改路径。「移除收藏」只删本地入口，不执行远端删除，也不弹远端删除确认。目录移动或更名后不会自动追踪。

收藏独立存放于应用数据目录的 `directory-bookmarks.json`，测试优先使用 `RABBITSHELL_DATA_DIR`。MainWindow 共享一个 DirectoryBookmarkStore，按稳定 profile.id 分域，每条有独立 ID；JSON 数组顺序即显示顺序，通过 QSaveFile 原子保存，失败显示反馈且不提前改变内存状态。每连接最多 256 项，总文件最多 4 MiB、2048 个连接域；异常文件保留，禁止覆盖。设置的「重置所有设置」仅清界面偏好，保留收藏。

路径只接受远端绝对 POSIX 路径，统一重复斜线和尾斜线、去除 `.` 段，拒绝 `..` 段及控制字符，保留大小写、中文、非 BMP 字符、空格和引号。不解析符号链接，不把不同词法路径当成同一远端位置。同一连接内规范化路径去重，不跨连接合并。终端仍由既有新 channel 的 shellQuote 路径启动逻辑处理。

连接中仅保留最新收藏意图；取消连接、断线、关闭、手动导航或刷新会撤销，移除收藏也撤销其待处理意图。迟到回复按 session、job、目录代次和最新请求校验，队列满的同步失败也不创建终端。连接身份更改时遵循已有旧工作区隔离规则。删除本地连接后旧工作区不能新增或修改收藏；原本地记录保留但不再显示或打开，不会由旧工作区重新创建连接或孤儿入口。离线 demo 不替不存在的正式连接保存收藏。

FileView、收藏树和连接管理树共用 SafeTreeWidget 的 Qt 公共可访问接口缓存失效维护，保留 0.1.23 的修复与析构前回调清理。该维护不重置业务模型，不禁用辅助功能，不重建 PTY 或文档。

别名同步关联组名，移除收藏只解除关联，最后一个终端关闭时清除关联。全组已结束时保留历史，再次打开创建一个新活动终端，之后继续复用。组头/终端提示明确显示【启动目录】，不宣称实时 cwd；手动命名优先，单终端隐藏管理树时顶部仍显示收藏归属。细节见 [0.1.35 设计](RabbitShell-应用锁与收藏终端组.md)。
