# RabbitShell 系统查询与应用菜单（0.1.36）

进程页上方提供可清空的本地纯文本筛选，按名称、PID、用户不区分大小写匹配，正则字符作为普通文本。筛选范围是当前监控已采集的前200个CPU进程，计数明确显示已采集数量；不会声称全系统完整进程。刷新保留筛选、PID身份、排序、列宽、选择和滚动，清空恢复已采集列表。没有匹配时显示明确空状态。

服务器状态页在进程概览附近增加最多五行的监听端口卡片；展开为编辑区的“监听端口”，与底部端口转发独立。完整表为协议、监听地址、端口、PID、进程。TCP只收LISTEN；UDP只收未连接的已绑定端点，不将其称为TCP监听。地址保留IPv4/IPv6、wildcard和IPv6接口scope。

采集优先`ss -H -lntup`，失败后尝试`netstat -lntup`；均不可用时明确提示，不安装工具、不提权、不遍历/proc进程、不逐端口执行ps、不写服务器隐藏文件。没有权限读取的进程字段显示“—”。PID/名称只表示当前用户可见归属之一，同端点可能被多个进程共享；不是唯一归属保证。

端口采集使用一条独立Commands SSH连接，复用已认证工作区凭据和同一主机指纹，不单独弹凭据或信任确认。每个工作区最多一条采集连接、一个在途请求；只有工作区已连接且应用解锁才可创建新连接/提交采样。复用原监控tick，前台状态/端口页采样间隔不短于5秒，后台不短于15秒（原tick调度可能使实际间隔更长）。每次命令最多2秒、512KiB，客户端最多4096个端点；超限/未完成不当作空列表，保留旧结果并显示过期。此连接增加少量SSH/线程状态，无无界样本缓存或独立常驻扫描计时器。失败和超时只结束采集worker，不中断用户主SSH、PTY或传输。

明确认证拒绝会停止自动重试，需工作区重连或更新认证再启用；旧身份晚到的信号被代次校验拒绝。断线、身份变更、工作区关闭会停止采集。监听页可关闭后重开、跨组移动、浮出/收回；复用原表和数据。锁中已有只读采样可完成，所有窗口由既有全局锁遮罩保护，锁中不启动新用户操作。

顶部菜单只调用已有能力。文件新建、上传与粘贴共用选中目录/文件所在目录解析；导航/草稿/链接不是有效目标。编辑命令依打开菜单前的焦点执行，文本和文件操作分开；终端复制调用原复制函数，绝不模拟Ctrl+C发送中断。没有有效文件粘贴内容时隐藏粘贴。切换工作区、销毁来源或跨越锁定代次后，旧菜单动作失效。主题切换共用完整工作区刷新入口；不新增全局快捷键。

平台通知、应用锁和密码安全边界继续遵循[应用锁与收藏终端组](RabbitShell-应用锁与收藏终端组.md)。本版没有变更远端文件恢复、PTY协议、凭据存储或终端组关联规则。
