## 资源和性能口径

- 延续 C++ / Qt Widgets / libssh2 / libvterm。外框和标题栏由系统绘制，不引入 WebEngine、QML 引擎、大面积透明层或循环动画。
- 应用图标为一次性生成的小型多分辨率位图；主题卡片按需绘制，没有运行中的动画定时器。
- 内存采样脚本分别输出 `PrivateBytesMiB`（私有提交）、`PrivateWorkingSetMiB`（私有工作集）与 `WorkingSetMiB`（总工作集）。这三项不相加。旧版脚本中的 `PrivateMiB` 实际表示私有提交。
- 私有工作集来自 Windows 性能计数器；计数器不可用时保留 null。CPU 使用进程 CPU 时间增量，按逻辑处理器总数归一化，首个样本没有 CPU 增量。
- 这次外观调整不宣称降低了特定比例的内存。完整性能验收仍需在相同场景下比较空连接管理、多终端、多文件、传输、反复开关浮窗和长期空闲等基线。

## 验证范围

- Release 编译及核心回归测试已通过，覆盖窗口位置恢复、负坐标屏幕、大窗口适配小工作区，以及文件浮窗隐藏/恢复/收回时保留内容。
- 本轮回归定位并修复了带 UTF-8 BOM 的远端内容重新载入时的临时数据生命周期问题，避免偶发乱码。包含每轮 32 次重新载入检查的核心测试连续运行 10 轮通过；隔离 SSH/SFTP 协议测试通过（0 failed / 0 skipped）。
- 测试运行器将 Qt 报告保存到构建目录再输出，Windows 上也能从 CTest 直接读取失败详情；网络测试未配置本机端口时明确标为跳过。
- `dist/RabbitShell-0.1.1/RabbitShell.exe` 完成了独立数据目录的隐藏启动检查，测试进程已清理，未结束用户正在使用的预览进程。内存脚本成功读取三种口径及 CPU，原始样本位于 `test-results/window-style-memory.json`。该场景未显示窗口、未建立连接，仅验证启动和采样能力，不作为实际交互内存基线。
- 在本机实际原生窗口中看到了 Dracula 标题栏、系统圆角、统一的内容背景和正常／最大化窗口。最终关闭按钮样式由后续 0.1.1 构建更新。
- 用户正在操作并最小化预览窗口时停止了自动输入，未抢占焦点；不将这段过程视为完整自动化验收。
- 浅色标题栏、两套主题预览卡片、窗口八方向缩放、贴靠、不同 DPI、跨屏、非活动状态和句柄重建仍需完成相应的桌面验收。自动几何测试不能替代真实混合 DPI 和窗口合成检查。
- Windows 高对比度开启时，原生标题栏优先系统颜色；应用内容区的完整高对比度模式尚未声明支持。

## 继续开发时的约定

界面调整继续遵循已确认的统一工作区和两套主题，不用参考组件的示例颜色替换产品主题。后续先补齐工作区实现记录中的功能缺口，再进行干净 Windows、macOS、Linux 的构建和实际界面验证。本文未覆盖的托盘、常驻后台、自定义标题栏和整窗动画不自动加入首版范围。

## 0.1.3 补充落实

保持原生标题栏、DWM 适配和系统外框。本轮仅增加内容分区边线、事件驱动的半透明 drop 预览与矢量图标按钮，不新增全窗透明或外层阴影。footer、状态卡片、传输浮层、资源／编辑／终端／连接管理分区均有独立 frame 语义；splitter 视觉 1px、命中宽 7px。规则已补入通用规范的 3.9 Frame 分区边界、3.10 纯图标工具按钮，两节使用通用表述。

连续左右分屏在同一水平容器插入相邻列，三列／四列保持同排与完整高度；显式上下方向才创建上下布局。新列只划分目标原空间，预览与放下位置一致。控件身份、撤销、草稿和终端进程保留；空组与退化容器延后清理，批量关闭和拖放嵌套循环都有生命周期保护。

本轮 Release、核心 9 项、分组 23 项、本机 SSH/SFTP fixture 3 项、凭据及活终端布局 fixture 14 项均为 0 failed / 0 skipped。常规 CTest 的 ssh_sftp 因无端口明确 skip，已另用隔离 runner 实际执行。两主题截图使用测试 setup 加载系统中文与等宽字体，核对过中文和浅色语法颜色；offscreen 的原生鼠标拖放与真实混合 DPI 仍须独立桌面验收。详见 [编辑分组验证](RabbitShell-编辑分组验证.md)。

原生桌面增量检查已由主代理在隔离 preview 窗口观察到拖影、中心／右侧预览、Esc 取消及中列移空后自动收起。工具合成 drag 需要追加同落点 click 才提交，故单手势 OLE 释放尚未完整确认；保留该边界，不将其算作全面鼠标验收。后续已确认同排三列／四列、其他列宽保留、半幅预览与最终位置一致，以及全部合并后的四文件／两终端内容保留。退出确认阶段用户按Esc停止桌面操作，后续未再控制窗口，是否退出未再核验。

## 0.1.4 顶部与目录层级

主窗口内容从服务器页签开始，删除重复应用头部及其 identity 成员；原生窗口标题继续显示当前服务器身份。页签右上角共享加号与设置入口，保留 20px 矢量图标、30px 点击区和键盘可达性。

资源管理采用紧凑目录按钮与装饰性矢量 chevron：`/ › home › demo › project`。根目录仅显示 `/`；当前目录适度加粗；名称保留真实大小写及 `&`，完整目标路径在 tooltip 中。最多展示最近三级，父级省略标记独立显示，当前目录优先留宽，长名称在按钮内部中间省略，不撑宽侧栏。箭头与省略标记均不参与键盘焦点。路径输入、Enter、Esc、失焦还原及现有导航流程沿用。本轮为 RabbitShell 产品调整，不改写 F 盘通用规范。

本轮验证使用独立临时配置和 offscreen，不操作用户桌面或连接。检查与截图见 `test-results/0.1.4/delivery-report.md`；offscreen 截图不包含 OS 合成的原生标题栏，不代替真实桌面窗口验收。
