# Scintilla 编辑器迁移

## 范围

按用户在左右对照中的选择，将正式 `CodeEdit` 从自定义 `QPlainTextEdit` 切换为官方 Scintilla 5.5.7 Qt 接口。主代理执行开发和验收，没有委派 Terra 或其他代理。迁移先以 0.1.46 本地试用包验收，经用户确认后纳入 0.1.47 正式发布。

旧路径在 Windows 反复拖选时，会进入 Qt 文本控件的辅助功能通知及 UI Automation/COM 等待；中文长行还会放大布局开销。此前的全局关闭辅助功能和定时合并通知实验均未采用。调查依据与实验边界见 `editor-selection-performance-plan.zh-CN.md`。

## 文档和绘制

- `EditorSurface` 适配 Scintilla 的原生输入、选择、撤销、滚动、行号和字号。正文只存储在内核中，没有用于兼容的隐藏 `QTextDocument`。
- `EditorDocument` 只保存修订号、修改状态和弱引用锚点。全文重设会使旧锚点失效；插入、删除按字节增量调整锚点。
- 搜索/诊断接口继续使用 UTF-16，内核使用 UTF-8。坐标转换使用 Scintilla 自带的增量 UTF-16 行索引，不在鼠标事件中扫描全文。
- `EditorLexer` 根据可视区域的 `styleNeeded` 增量着色，保持原来的基础语法规则、字符串/注释优先级和两套主题；语法校验仍由原后台校验器执行。
- 搜索命中、定位行和错误波浪线使用 native indicators/markers，普通选区使用内核选区颜色。不会在每次拖动时重建上万个搜索标记、更新样式表或全文解析。
- 当前行外框使用根据内核几何绘制的轻量叠加层。Scintilla 的 caret-line 可见性设置会使布局缓存失效，不能用它在每次选择/取消选择时切换外框。叠加层只更新受影响的行，不拥有独立文本布局。
- 布局缓存限定为 `SC_CACHE_PAGE`，不缓存整个文档来换取拖选速度。默认 14px 字号保持约 19px 行高；字重 500、字号偏好和全应用缩放继续生效。
- 短片段宽度缓存改为 256 个小于 128 字节的条目，覆盖内核约 100 字节的布局片段；原来是 1024 个小于 30 字节的条目。最大文字和宽度数据预算接近原值，不随文档长度增长，也不改写字符宽度。

## 保留的行为

Ctrl+F 查找/替换、大小写/全字/正则、保留大小写替换、命中数和上下跳转、定位居中；高级搜索唯一结果面板、来源固定、编辑后锚点跟随、重叠修改判过期、来源关闭后重开；清空/关闭搜索时仅移除所属装饰与选区；手动选区和错误提示独立保留。

文件编码保护、BOM、CRLF/LF、只读、未保存提示和现有保存流程保持原有规则。工作区页签重排、多文件分屏、浮窗仍使用同一编辑器对象，移动视图不会重建正文或清空撤销记录。没有新增远端工具、文件或后台服务。

## 辅助功能

只为 `EditorSurface` 注册文本/编辑接口，支持 UTF-16 文本读取、实时选择、光标位置、字符位置和编辑命令。保留 Qt 的辅助功能系统；拖动过程中可主动查询实时选区，但将该手势的选择变更通知放到释放鼠标时发送。键盘/程序定位继续发送通知；真实文本变更发送文本更新事件。没有全局禁用 UIA。

## 验证入口

`tests/test_editorengine.cpp` 验证中文/emoji/组合字符的位置换算、锚点、成组撤销、重设失效、BOM/换行、只读、IME 提交、词法状态、文本辅助接口和对象释放。原高亮、搜索、语法诊断、外观、编辑分组、工作区、菜单和内存测试保留其行为断言，并适配内核接口。外观测试同时修正了旧的“设置菜单位于最后一项”、无焦点标签必然获取焦点和端口行仍为双行的过期测试假设。

`tests/probe_editor_selection.cpp` 提供隔离的完整功能窗口及计时入口，不读取真实连接配置，不连接 SSH，不操作系统剪贴板。计时按输入前后真实选区是否改变分类，将选区与首次对应绘制关联；无须重画的输入不算丢帧，未对应输入的绘制单独计数。计时是应用注入事件到 QWidget 绘制完成，不是物理鼠标到屏幕呈现的延迟。

`tests/probe_editor_memory.cpp` 反复打开、分屏、浮窗、修改/撤销和关闭，检查编辑器、文档元数据、词法器及页签按钮的生存期。不得用强制收缩工作集制造内存下降。

本地构建为 Windows x64、MSVC v143 Release、Qt 6.8.3。依赖采用跨平台 Qt 接口；Linux/macOS 的实际构建、输入法和窗口系统表现仍需在对应系统验收，Windows 测试不能代替这部分验证。

## 构建与许可

CMake 固定官方 Scintilla 源码和 SHA-256。Qt 需安装 `qt5compat`；Windows CI 已添加此模块，打包脚本要求实际部署 `Qt6Core5Compat.dll`。字体适配只修改经过校验的构建副本，来源、许可和改动见 `third_party/patches/scintilla-5.5.7.md` 与 `third_party/licenses/Scintilla.txt`。

## 2026-11-13 本地验收

最后一轮计时记录：`test-results/selection-investigation-20261113/windows-migrated-cache.json`。3 轮、24 组，每组 160 次应用注入移动，覆盖有无语法/搜索装饰、同屏往返及滚动拖选。普通文件 3000 行；长行文件约 126 万 UTF-16 单元，每行含大量中文、emoji 和组合字符。

| 情况 | 各组输入至对应绘制 p95 | 最慢单次 |
| --- | --- | --- |
| 普通文件，含滚动和装饰 | 2.19–5.46 ms | 6.70 ms |
| 长混排行，同屏往返 | 4.71–5.35 ms | 6.36 ms |
| 长混排行，持续滚动 | 11.32–14.60 ms | 62.79 ms |

1846 次真实选区变化均找到对应绘制。p95 达到调查计划中约 16.7 ms 的目标；长行滚动有一组 p99 为 47.04 ms，超过约 33 ms 的目标，仍有少量慢帧。不能描述为任何文件都无卡顿，也不将该值换算成物理输入延迟、屏幕帧率或整体提升百分比。宽度缓存对重复片段有收益，内容完全不同的长行不能据此保证同等结果。

此前字形位置改写试验未获得足够的整体收益，未合入；最终保留上游的字符测量与文字塑形，仅调整有界短片段缓存的预算分配。不要把 `windows-migrated-glyphs.json`、`windows-migrated-final.json` 或早期未关联真实选区的计时当作当前交付结果。

最终相关回归 8/8 通过：`editor_engine`、`syntax_diagnostics`、`editor_highlights`、`document_search`、`menus`、`appearance`、`editor_groups`、`workspace`。日志为 `build-scintilla/editor-regression-final.txt`。

内存验证 `migrated-memory-final/memory-scintilla.json` 完成 3 轮热身与 25 轮正式生命周期操作。每次关闭后编辑器、文档元数据、着色器和被追踪对象均为 0；控件数量保持 463。关闭后的私有内存约 36.69–40.51 MiB，最后约 39.53 MiB。句柄一次上升后保持稳定，未随剩余轮数逐轮增长。缓存/分配器保留不等于对象泄漏；没有调用工作集压缩来伪造下降。

目录包在仅使用部署 DLL、最小 PATH 和临时配置目录的条件下，版本命令、连接管理启动和离线工作区启动通过。Qt Core5Compat 已随包部署。两套主题、查找/替换、选择、当前行及错误红线的自动渲染证据位于 `build-scintilla/editor-highlights/` 和 `build-scintilla/syntax-diagnostics-evidence/`。

桌面实操最初遇到 Windows 锁屏，解锁后已检查拖选、中文查找和两套主题；用户随后确认该版本没有问题。系统输入法候选窗口及完整手工替换流程尚未覆盖，IME 提交有自动测试。没有连接真实服务器，也没有读写真实配置或系统剪贴板。

## 历史试用包

单文件入口：`dist/FrogShell-Scintilla-preview.exe`，目录包为 `dist/FrogShell-editor-preview-20261113/`。这是基于 0.1.46 的本地迁移验收包；正式交付使用 GitHub 的 0.1.47 及后续版本。运行普通入口前从托盘退出旧版，否则单实例机制会唤起旧版。可使用 `--data-dir <独立目录>` 以独立配置试用。
